## 一、模块外观识别

### 1.1 常见模块形式

由于您购买的是"已做成模块"的芯片，可能是以下形式之一：

| 模块类型 | 特点 | 识别方法 |
|----------|------|----------|
| **核心板** | 最小系统，引出主要引脚 | 有晶振、电容、排针 |
| **开发板** | 带USB、按键、LED | 有USB接口、多个元件 |
| **转接板** | 仅将QFN引脚引出 | 小板，两面有焊盘 |
| **成品模块** | 带天线、已烧录程序 | 有PCB天线或外接天线 |

### 1.2 引脚识别

无论模块形式如何，关键引脚通常都会引出：

**必须引出的引脚**：
```
VCC  → 3.3V电源输入
GND  → 地
SWS  → 烧录接口
TX   → UART发送 (PB1)
RX   → UART接收 (PB2)
```

**可能引出的引脚**：
```
PA0-PA5 → PWM输出
PB0/PB3 → I2C接口
PC0-PC5 → ADC输入
PD0/PD1 → GPIO
```

## 二、模块测试步骤

### 2.1 上电前检查

```
□ 检查电源电压：3.3V（严禁5V！）
□ 检查电源极性：VCC和GND不要接反
□ 检查模块外观：无短路、无烧毁痕迹
□ 准备USB转串口模块：用于调试
```

### 2.2 首次上电测试

```
步骤1：连接电源
   ├─ VCC → 3.3V
   ├─ GND → GND
   └─ 电流限制：建议串联100Ω电阻，限制电流

步骤2：观察电流
   ├─ 正常电流：5-15mA（空闲状态）
   ├─ 如果电流>50mA：可能短路，立即断电
   └─ 如果电流=0：可能断路或芯片损坏

步骤3：检查晶振
   ├─ 用示波器检查24MHz晶振波形
   └─ 如果没有波形：检查晶振连接

步骤4：检查UART输出
   ├─ 连接USB转串口模块
   ├─ 波特率：115200
   ├─ 观察是否有输出
   └─ 如果有乱码：检查波特率设置
```

### 2.3 烧录测试程序

如果模块已有程序，可以先测试；如果没有，需要烧录测试程序。

**测试程序功能**：
- LED闪烁（PD1引脚）
- UART输出"Hello TLSR8269"
- PWM输出测试波形

## 四、模块引脚扩展

### 4.1 如果模块引脚不全

如果购买的模块只引出了部分引脚，需要：

#### 方案1：飞线扩展

```
使用漆包线或细导线，从QFN引脚直接引出
注意：
├─ 焊接温度≤350°C
├─ 焊接时间<3秒
├─ 使用放大镜辅助
└─ 避免短路相邻引脚
```

#### 方案2：转接板

```
设计PCB转接板，将QFN引脚引出为排针
优点：
├─ 连接可靠
├─ 便于调试
└─ 可重复使用
```

#### 方案3：重新焊接

```
如果模块是核心板，可以直接在核心板上焊接排针
注意：
├─ 确认核心板引脚已引出
├─ 使用合适的排针间距（2.54mm）
└─ 注意引脚对应关系
```

### 4.2 推荐引脚分配（本项目）

| 功能 | 引脚 | 连接方式 |
|------|------|----------|
| PWM输出 CH0-5 | PA0-PA5 | 排针或飞线 |
| I2C SCL/SDA | PB0/PB3 | 排针 |
| UART TX/RX | PB1/PB2 | 排针（调试） |
| ADC输入 | PC0-PC5 | 排针或飞线 |
| 急停按钮 | PD0 | 排针 |
| 状态LED | PD1 | 排针或直接焊接LED |
| 电源 | VCC/GND | 排针 |
| 烧录 | SWS/RESET | 排针或测试点 |

## 五、模块测试程序

### 5.1 最小测试程序

```c
// test.c - TLSR8269最小测试程序
#include "tl_common.h"
#include "drivers.h"

// LED引脚定义
#define LED_PIN     GPIO_PD1

void main(void) {
    // 初始化时钟
    cpu_wakeup_init();
    
    // 初始化GPIO
    gpio_set_func(LED_PIN, AS_GPIO);
    gpio_set_output_en(LED_PIN, 1);
    gpio_write(LED_PIN, 0);
    
    // 初始化UART
    uart_init(115200);
    uart_send_string("Hello TLSR8269!\r\n");
    
    while(1) {
        // LED闪烁
        gpio_write(LED_PIN, 1);
        uart_send_string("LED ON\r\n");
        sleep_ms(500);
        
        gpio_write(LED_PIN, 0);
        uart_send_string("LED OFF\r\n");
        sleep_ms(500);
    }
}
```

### 5.2 PWM测试程序

```c
// pwm_test.c - PWM输出测试
#include "tl_common.h"
#include "drivers.h"

void main(void) {
    cpu_wakeup_init();
    uart_init(115200);
    
    uart_send_string("PWM Test Start\r\n");
    
    // 初始化6路PWM
    for(int i=0; i<6; i++) {
        pwm_set_clk(i, PWM_CLK_48M);
        pwm_set_cycle_and_duty(i, 1000, 500); // 50%占空比
        pwm_start(i);
        uart_send_string("PWM CH");
        uart_send_digit(i);
        uart_send_string(" Started\r\n");
    }
    
    while(1) {
        sleep_ms(1000);
    }
}
```

### 5.3 ADC测试程序

```c
// adc_test.c - ADC输入测试
#include "tl_common.h"
#include "drivers.h"

void main(void) {
    cpu_wakeup_init();
    uart_init(115200);
    
    uart_send_string("ADC Test Start\r\n");
    
    // 初始化ADC
    adc_init();
    
    while(1) {
        for(int i=0; i<6; i++) {
            int value = adc_sample(i);
            uart_send_string("ADC CH");
            uart_send_digit(i);
            uart_send_string(" = ");
            uart_send_digit(value);
            uart_send_string("\r\n");
        }
        sleep_ms(1000);
    }
}
```

## 六、常见问题排查

### 6.1 模块无法上电

| 现象 | 原因 | 解决方法 |
|------|------|----------|
| 电流=0 | 电源未接好 | 检查电源连接 |
| 电流=0 | 芯片损坏 | 更换模块 |
| 电流过大 | 短路 | 检查是否有焊锡桥接 |
| 电流波动 | 电源不稳 | 增加去耦电容 |

### 6.2 无法烧录

| 现象 | 原因 | 解决方法 |
|------|------|----------|
| 无法连接 | SWS引脚未连接 | 检查SWS连接 |
| 无法连接 | 芯片损坏 | 更换模块 |
| 烧录失败 | Flash保护 | 先解锁Flash |
| 烧录失败 | 固件不兼容 | 检查芯片型号 |

### 6.3 程序不运行

| 现象 | 原因 | 解决方法 |
|------|------|----------|
| LED不亮 | 程序未运行 | 检查复位电路 |
| LED不亮 | 引脚错误 | 检查LED引脚定义 |
| UART无输出 | 波特率错误 | 检查波特率设置 |
| UART无输出 | TX/RX接反 | 交换TX/RX连接 |

### 6.4 PWM无输出

| 现象 | 原因 | 解决方法 |
|------|------|----------|
| 无波形 | 引脚未配置 | 检查GPIO配置 |
| 无波形 | 时钟未使能 | 检查PWM时钟 |
| 波形异常 | 占空比错误 | 检查占空比设置 |
| 波形异常 | 频率错误 | 检查频率设置 |

## 七、模块改造建议

### 7.1 增加排针

如果模块没有排针，建议增加：

```
所需材料：
├─ 1×40排针（2.54mm间距）
├─ 电烙铁（温度可调）
├─ 焊锡丝
└─ 助焊剂

焊接步骤：
1. 将排针插入面包板固定
2. 将模块放在排针上
3. 焊接每个引脚
4. 检查是否有虚焊
```

### 7.2 增加测试点

对于关键信号，建议增加测试点：

```
测试点位置：
├─ VCC和GND → 电源测试点
├─ SWS和RESET → 烧录测试点
├─ TX和RX → 调试测试点
└─ PA0-PA5 → PWM测试点

测试点形式：
├─ 过孔焊盘
├─ 测试钩焊盘
└─ 排针
```

### 7.3 增加标识

为了避免混淆，建议在模块上增加标识：

```
标识内容：
├─ 芯片型号：TLSR8269
├─ 引脚编号：1-32
├─ 功能标注：VCC、GND、SWS等
└─ 方向标识：Pin 1位置

标识方法：
├─ 丝印（如果重新做PCB）
├─ 标签纸
└─ 记号笔
```

## 九、注意事项

### 9.1 防静电

```
防静电措施：
├─ 佩戴防静电手环
├─ 工作台铺防静电垫
├─ 模块放在防静电袋中
└─ 避免在干燥环境操作
```

### 9.2 防短路

```
防短路措施：
├─ 模块放在绝缘垫上
├─ 避免金属工具接触引脚
├─ 焊接时注意不要桥接
└─ 测试时使用限流电源
```

### 9.3 防过压

```
防过压措施：
├─ 电源电压严格3.3V
├─ 严禁使用5V
├─ 使用稳压电源
└─ 增加过压保护电路
```
