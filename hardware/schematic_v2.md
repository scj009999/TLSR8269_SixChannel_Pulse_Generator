## 1. 电源电路（医疗级隔离）

### 1.1 主电源输入

```
    USB 5V 或 18650电池(3.7V)
              │
              ├─[保险丝F1 500mA]──┬─── 过流保护
              │                   │
              ├─[TVS管 5V]───────┤    过压保护
              │                   │
              ├─[10µF]──┬────────┤    输入滤波
              │         │        │
              │    ┌────┴────┐   │
              └────┤  LDO    ├───┼─── 3.3V控制电路
                   │AMS1117  │   │
                   │3.3V     │   │
                   └────┬────┘   │
                        │        │
                        ├─[100nF]┤    去耦
                        │        │
                        ├─[10µF]─┤    输出滤波
                        │        │
                        └────────┘
```

### 1.2 隔离DC-DC（患者电路）

```
    5V输入
      │
      ├─[10µF]──┬──────────────┐
      │         │              │
      │    ┌────┴────────┐     │
      └────┤  B0505S-1W  ├─────┼─── 隔离5V输出
           │  隔离DC-DC  │     │
           │  3000V隔离   │     │
           └────┬────────┘     │
                │              │
                ├─[10µF]───────┤    输出滤波
                │              │
                ├─[100nF]──────┤    高频去耦
                │              │
                └──────────────┘
                
    隔离地(ISOGND) ──────── 单独铺铜，与系统地单点连接
```

**器件参数**：
- B0505S-1W：输入5V，输出5V，隔离电压3000VDC，功率1W
- 或 B0503.3S-1W：直接输出3.3V（推荐，减少一级LDO）

```
    TLSR8269 PA0 (PWM0)
         │
         │ (3.3V逻辑电平)
         ▼
    ┌─────────┐
    │  限流    │
    │  电阻    │
    │  330Ω   │  ← 限制LED电流，保护光耦
    └────┬────┘
         │
         ▼
    ┌─────────┐
    │  PC817   │  ← 光耦隔离，隔离电压5000V
    │  光耦    │
    │  (1)     │──── 阳极
    │  (2)     │──── 阴极
    │  (3)     │──── 发射极 ────► 电极输出 -
    │  (4)     │──── 集电极 ────► 电极输出 +
    └─────────┘
         │
         │ (隔离侧，ISOGND)
         ▼
    ┌─────────┐
    │  限流    │
    │  电阻    │
    │  100Ω   │  ← 核心限流电阻，限制电流<33mA@3.3V
    └────┬────┘
         │
         ▼
    ┌─────────┐
    │  电极    │
    │  输出    │
    │  CH0+   │
    └─────────┘
         │
         ├─[100nF]─ ISOGND  ← 高频滤波
         │
         ▼
    ┌─────────┐
    │  电极    │
    │  输出    │
    │  CH0-   │
    └─────────┘
         │
         ▼
        ISOGND
```

### 6.2 六路输出汇总

```
    ┌─────────────────────────────────────────┐
    │           光耦隔离阵列                   │
    │                                         │
    │  PA0 ──► PC817 ──► CH0+ (经100Ω限流)   │
    │  PA1 ──► PC817 ──► CH1+                │
    │  PA2 ──► PC817 ──► CH2+                │
    │  PA3 ──► PC817 ──► CH3+                │
    │  PA4 ──► PC817 ──► CH4+                │
    │  PA5 ──► PC817 ──► CH5+                │
    │                                         │
    │  所有CHx- 连接到 ISOGND                 │
    │                                         │
    └─────────────────────────────────────────┘
```

### 6.3 电流检测电路（每通道）

```
    电极输出CHx+
         │
         ├──────────────────────────► 到电极
         │
    ┌────┴────┐
    │  采样   │
    │  电阻   │
    │  1Ω    │  ← 1Ω采样电阻，提高精度
    └────┬────┘
         │
         ▼
    ┌─────────┐
    │  差分   │
    │  放大   │
    │  器     │  ← 可选，用于提高小信号精度
    └────┬────┘
         │
         ▼
    TLSR8269 ADC (PC1-PC6)
```

**电流计算**：
- 采样电阻：1Ω
- 电流1mA时，压降：1mV
- 10位ADC分辨率：3.3V/1024 ≈ 3.2mV
- 理论分辨率：约3.2mA（不够）

**改进方案**：使用INA219

```
    电极输出CHx+
         │
    ┌────┴──────────────┐
    │                   │
    │  INA219          │  ← I2C电流检测芯片
    │  (I2C地址可配置)  │
    │                   │
    │  SDA ────────────┼──► TLSR8269 I2C_SDA
    │  SCL ────────────┼──► TLSR8269 I2C_SCL
    │  VCC ────────────┼─── 3.3V
    │  GND ────────────┼─── GND
    └───────────────────┘
```

**INA219优势**：
- 精度：±0.5%
- 分辨率：12位ADC，可检测10µA级电流
- 内置分流电阻：0.1Ω
- I2C接口，易于集成

## 7. 急停按钮电路

```
    VCC (3.3V)
      │
      ├─[10kΩ]────┬─── PE0 (Pin 41) ──► TLSR8269
      │            │                     (配置为中断输入)
      │       ┌────┴────┐
      │       │  急停   │
      │       │  按钮   │  ← 红色大按钮，硬件中断
      │       │ (常闭)  │
      │       └────┬────┘
      │            │
     GND          GND
     
    注意：按钮按下时，PE0从高电平变为低电平，触发中断
```

**中断配置**：
```cpp
// Arduino代码
attachInterrupt(digitalPinToInterrupt(STOP_PIN), emergencyStop, FALLING);
```

## 11. PCB布局建议

### 11.1 分层结构

```
┌────────────────────────────────────────┐
│  Top Layer (信号层)                     │
│  - TLSR8269                            │
│  - 光耦阵列 (靠近输出端子)               │
│  - 电极输出端子                         │
├────────────────────────────────────────┤
│  Inner Layer 1 (地平面)                 │
│  - 完整铺地                            │
│  - 单点连接隔离地                       │
├────────────────────────────────────────┤
│  Inner Layer 2 (电源层)                 │
│  - 3.3V电源平面                        │
│  - 隔离电源平面                        │
├────────────────────────────────────────┤
│  Bottom Layer (信号层)                  │
│  - LDO、DC-DC                          │
│  - 晶振                                │
│  - 调试接口                            │
└────────────────────────────────────────┘
```

### 11.2 关键布局要点

1. **隔离区域划分**：
   ```
   ┌────────────────────────────────────┐
   │  控制电路区  │  隔离带  │  患者电路区 │
   │  (系统地)   │ (≥3mm)  │  (隔离地)  │
   │             │         │            │
   │  TLSR8269   │  光耦   │  输出端子   │
   │  LDO        │  阵列   │  限流电阻   │
   │  晶振       │         │  滤波电容   │
   │             │         │            │
   └────────────────────────────────────┘
   ```

2. **去耦电容布局**：
   - 每个VCC引脚旁放置100nF电容
   - 电容接地回路尽量短
   - 避免过孔串联

3. **光耦布局**：
   - 光耦横跨隔离带
   - 输入侧（控制侧）靠近TLSR8269
   - 输出侧（患者侧）靠近输出端子

4. **电流检测**：
   - 采样电阻靠近输出端子
   - 走线尽量短，减少噪声
   - 差分走线（如果使用差分放大）

## 13. 安全测试清单

打板前必须确认：

- [ ] 隔离电压≥3000VDC（B0505S-1W规格）
- [ ] 限流电阻计算正确：3.3V/100Ω=33mA（最坏情况）
- [ ] 光耦隔离电压≥5000V（PC817规格）
- [ ] 急停按钮为常闭型，按下断开
- [ ] 保险丝500mA，保护电池和电路
- [ ] TVS管5V，保护USB输入
- [ ] 所有患者侧电路与系统地隔离
- [ ] 单点接地，避免地环路

---

## 14. 打板注意事项

1. **板材**：FR-4，1.6mm厚度
2. **层数**：4层（推荐）或2层（成本考虑）
3. **铜厚**：1oz（标准）
4. **表面处理**：HASL或无铅喷锡
5. **阻焊**：绿色（标准）
6. **丝印**：白色，清晰标注引脚功能
7. **隔离带**：光耦下方挖空或保持3mm间距
