## 四、关键布局要点

### 4.1 晶振布局

```
要求：
- 晶振Y1距离芯片U1 < 20mm
- 负载电容C4/C5紧靠晶振
- 走线等长、对称
- 下方禁止走其他信号线

布局：
        U1 (100,65)
          │
          │ 15mm
          ▼
        Y1 (115,60)
       ┌─────┐
    C4 │     │ C5
   (110,55) (120,55)
```

### 4.2 电源去耦

```
要求：
- 去耦电容紧靠电源引脚
- C7/C8距离U1的VCC引脚 < 5mm
- 过孔直接连接到GND层

布局：
     U1 Pin 23,24 (VCC)
         │
    ┌────┴────┐
    ▼         ▼
   C7        C8
  (95,70)  (105,70)
```

### 4.3 光耦跨接隔离带

```
要求：
- 光耦本体跨接隔离带
- 引脚1-2在控制侧
- 引脚3-4在患者侧
- 隔离距离 ≥ 3mm

布局：
    控制侧 │ 隔离带 │ 患者侧
           │        │
    U4 Pin1├────────┤Pin4
    U4 Pin2├────────┤Pin3
           │  3mm   │
```

### 4.4 电位器位置

```
要求：
- 易于用户操作
- 远离高频信号
- 滤波电容紧靠抽头

布局：
    RV1 (60,70) - 板左侧边缘
      │
      ├─── R5 (55,65) - 分压电阻
      │
      ├─── C6 (60,75) - 滤波电容
      │
      └─── 到 U1 Pin 11 (ADC0)
```

## 五、布线规则

### 5.1 线宽规则

| 网络类型 | 线宽 | 说明 |
|----------|------|------|
| 电源 (+3.3V, +5V) | 0.5mm | 大电流 |

| 光耦两侧 | 3.0mm | 爬电距离 |

## 七、铺铜设计

### 7.1 顶层铺铜 (F.Cu)

```
区域：控制侧 (Y: 40-82mm)
网络：GND
方式：实心铺铜
连接：热焊盘连接

注意：
- 隔离带区域不铺铜
- 患者侧不铺控制侧GND
- 晶振下方禁止铺铜
```

### 7.2 底层铺铜 (B.Cu)

```
区域1：控制侧 (Y: 40-82mm)
网络：GND
方式：实心铺铜

区域2：患者侧 (Y: 88-120mm)
网络：ISO_GND
方式：实心铺铜

注意：
- 隔离带区域不铺铜
- 两个GND网络完全分离
```
