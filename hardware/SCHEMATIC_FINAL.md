### 2.2 电源电路

```
                    ┌─────────┐
    USB 5V ─────────┤IN       │
    或电池+         │ AMS1117 │
                    │  -3.3   │
    GND ────────────┤GND      │
                    │         │
    3.3V ───────────┤OUT      │
                    └─────────┘
                         │
                    ┌────┴────┐
                    │ 10µF    │ 输入滤波
                    │ 陶瓷    │
                    └─────────┘
                         │
                    ┌────┴────┐
                    │ 10µF    │ 输出滤波
                    │ 陶瓷    │
                    └─────────┘
```

**参数**：
- 输入：4.5V-12V（USB 5V或3.7V锂电池+升压）
- 输出：3.3V ±2%
- 电流：最大1A
- 压差：1V@1A

### 2.3 PWM输出电路（每通道）

```
    PA0 (PWM0) ──────┬─────► 到光耦
                     │
                ┌────┴────┐
                │  100Ω   │ 限流电阻
                │         │
                └─────────┘
```

**6通道相同设计**：
- CH0: PA0 → 100Ω → 光耦
- CH1: PA1 → 100Ω → 光耦
- CH2: PA2 → 100Ω → 光耦
- CH3: PA3 → 100Ω → 光耦
- CH4: PB0 → 100Ω → 光耦
- CH5: PB1 → 100Ω → 光耦

                     │                 │
                     │    ┌─────┐      │

**参数**：
- 光耦：PC817

- 电流传输比：50-600%
- 输出限流：100Ω（最大33mA@3.3V）

## 四、PCB设计要点

```
┌─────────────────────────────────────────┐
│  [USB]      [OLED]        [电位器]      │
│                                         │
│  [U2]                                   │

│  电极输出                               │
│                                         │
│  [按键区]                               │
│  UP DOWN LEFT RIGHT OK CANCEL           │
│  START STOP                             │
│                                         │
└─────────────────────────────────────────┘
```

### 4.2 关键设计规则

| 参数 | 值 | 说明 |
|------|-----|------|
| 板厚 | 1.6mm | 标准 |
| 铜厚 | 1oz | 标准 |
| 最小线宽 | 0.2mm | 嘉立创工艺 |
| 最小间距 | 0.2mm | 嘉立创工艺 |
| 过孔 | 0.3/0.6mm | 钻孔/焊盘 |
| 阻焊 | 绿色 | 标准 |
| 丝印 | 白色 | 标准 |

### 4.3 注意事项

1. **电源完整性**
   - 3.3V电源线宽度≥0.5mm
   - 每个芯片附近放置去耦电容
   - 电源入口放置大容量滤波电容

2. **信号完整性**
   - PWM输出线等长设计
   - I2C线长度<10cm
   - 晶振靠近MCU，走线短

3. **医疗安全**
   - 光耦隔离区域挖空（无铜）
   - 输入输出隔离距离≥2mm
   - 高压区域标识清晰

4. **散热**
   - TLSR8269底部散热焊盘接地
   - 打9个过孔（0.3mm）
   - 光耦和稳压器适当远离
