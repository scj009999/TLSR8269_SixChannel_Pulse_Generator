# PCB打板前检查清单

## 一、电气安全检查

### 1.1 隔离设计 ✅
- [ ] 患者电路与控制电路隔离≥3000VDC
- [ ] 光耦隔离电压≥5000V（PC817）
- [ ] 隔离DC-DC（B0505S-1W）正确连接
- [ ] 隔离地（ISOGND）与系统地（GND）单点连接
- [ ] 隔离带宽度≥3mm

### 1.2 限流保护 ✅
- [ ] 每通道100Ω限流电阻（患者侧）
- [ ] 最坏情况电流：3.3V/100Ω=33mA（<50mA安全限值）
- [ ] 光耦输入330Ω限流电阻
- [ ] 保险丝500mA（自恢复型）

### 1.3 过压保护 ✅
- [ ] TVS管5V（USB输入保护）
- [ ] LDO输入电容≥10µF
- [ ] 电池保护板（过充/过放/短路）

### 1.4 急停电路 ✅
- [ ] 急停按钮为常闭型
- [ ] 连接到硬件中断引脚（PE0）
- [ ] 10kΩ上拉电阻
- [ ] 按钮按下时：高电平→低电平（FALLING触发）
