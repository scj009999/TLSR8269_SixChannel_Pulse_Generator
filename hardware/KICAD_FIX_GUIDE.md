# KiCad原理图修复指南

> **日期**：2026-05-14  
> **问题**：KiCad读取原理图不正常  
> **作者**：开源医疗项目团队

---

## 一、问题描述

### 1.1 现象

用户反馈：使用KiCad助手生成的原理图读取不正常。

### 1.2 根本原因

经过分析，发现以下问题：

| 问题 | 说明 | 影响 |
|------|------|------|
| **文件格式错误** | 截图显示PNG图片，不是KiCad原理图文件 | KiCad无法打开 |
| **原理图不完整** | 现有.kicad_sch文件只有基本符号，缺少实际电路 | 打开后显示空白或错误 |
| **版本不兼容** | 混合使用KiCad 5 (.sch) 和 KiCad 6+ (.kicad_sch) 格式 | 可能无法正确读取 |
| **缺少关键元件** | 没有芯片符号、PWM电路、光耦隔离等 | 原理图功能不完整 |

---

## 二、解决方案

### 2.1 立即修复步骤

#### 步骤1：确认文件格式

确保您打开的是正确的KiCad原理图文件：

| 格式 | 扩展名 | 适用KiCad版本 |
|------|--------|--------------|
| KiCad 5 | `.sch` | KiCad 5.x |
| KiCad 6+ | `.kicad_sch` | KiCad 6.0+ |
| 项目文件 | `.kicad_pro` | KiCad 6.0+ |

**不要打开PNG图片文件！**

#### 步骤2：使用正确的KiCad版本

根据原理图格式选择KiCad版本：

```
如果是 .sch 文件 → 使用 KiCad 5.x
如果是 .kicad_sch 文件 → 使用 KiCad 6.0+
```

#### 步骤3：检查文件完整性

打开原理图文件前，确认：
- [ ] 文件大小 > 1KB（空文件通常几百字节）
- [ ] 文件内容包含 `(kicad_sch` 或 `EESchema` 头
- [ ] 文件路径没有中文或特殊字符

### 2.2 重新生成正确原理图

#### 方法A：使用KiCad自带转换工具

如果您有KiCad 5格式的 `.sch` 文件：

1. 打开KiCad 6+
2. 选择 **文件 → 打开**
3. 选择 `.sch` 文件
4. KiCad会自动提示转换
5. 保存为 `.kicad_sch` 格式

#### 方法B：手动创建新原理图

如果现有文件损坏，建议重新创建：

1. 打开KiCad 6+
2. 创建新项目
3. 打开原理图编辑器
4. 添加元件：
   - 芯片：CR8269F512E132TKM1815
   - 电阻、电容
   - 晶振
   - 连接器
5. 连接线路
6. 保存

#### 方法C：使用文本编辑器修复

如果文件部分损坏，可以尝试手动修复：

1. 用文本编辑器（VS Code、Notepad++）打开 `.kicad_sch`
2. 检查是否有语法错误：
   - 括号是否匹配
   - 引号是否闭合
   - UUID是否唯一
3. 修复错误后保存
4. 用KiCad重新打开

```

    (path "/" (page "1"))
  )

```

## 四、常见问题排查

### 4.1 问题：KiCad打开后空白

**原因**：
- 原理图没有实际元件
- 元件在视图范围外

**解决**：
1. 按 **Home** 键居中视图
2. 检查是否有元件（看右侧面板）
3. 如果没有，需要添加元件

### 4.2 问题：提示"无法解析文件"

**原因**：
- 文件格式错误
- 文件损坏
- 编码问题

**解决**：
1. 确认文件扩展名正确
2. 用文本编辑器检查文件头
3. 尝试用KiCad转换工具

### 4.3 问题：缺少符号库

**原因**：
- 自定义符号未找到
- 库路径错误

**解决**：
1. 打开 **偏好设置 → 符号库**
2. 添加自定义库路径
3. 确保库文件存在

### 4.4 问题：中文路径导致错误

**原因**：
- KiCad对中文路径支持不完善

**解决**：
1. 将项目移动到英文路径
2. 例如：`D:\Projects\TLSR8269\`
3. 重新打开项目
