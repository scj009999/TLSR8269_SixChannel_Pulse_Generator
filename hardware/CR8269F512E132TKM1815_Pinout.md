## 三、功能分组详解

### 3.1 PWM输出（6路）

```
PA0 → PWM0 → CH0 → 脉冲输出通道0
PA1 → PWM1 → CH1 → 脉冲输出通道1
PA2 → PWM2 → CH2 → 脉冲输出通道2
PA3 → PWM3 → CH3 → 脉冲输出通道3
PA4 → PWM4 → CH4 → 脉冲输出通道4
PA5 → PWM5 → CH5 → 脉冲输出通道5
```

**PWM参数**：
- 频率范围：1Hz - 8MHz
- 占空比精度：0.01%
- 输出模式：可配置为互补输出
- 死区控制：支持（用于H桥驱动）

---

### 3.2 ADC输入（6路）

```
PC0 → ADC0 → 电池电压监测
PC1 → ADC1 → 电流检测 CH0
PC2 → ADC2 → 电流检测 CH1
PC3 → ADC3 → 电流检测 CH2
PC4 → ADC4 → 电流检测 CH3
PC5 → ADC5 → 电流检测 CH4
```

**ADC参数**：
- 分辨率：12位
- 采样率：最高200ksps
- 输入范围：0 - 3.3V
- 内置参考电压：可选

**注意**：QFN32只有6路ADC，如果需要6路电流检测+电池监测，建议：
- **方案1**：使用INA219 I2C接口，不占用ADC
- **方案2**：外部ADC芯片（如ADS1115，4通道16位）
- **方案3**：多路复用器（如CD4051）

---

### 3.3 I2C接口

```
PB0 → I2C_SCL → INA219 SCL (电流检测芯片)
PB3 → I2C_SDA → INA219 SDA (电流检测芯片)
```

**I2C参数**：
- 速率：标准模式100kHz / 快速模式400kHz
- 支持多设备（通过地址区分）
- 可连接：INA219、OLED显示屏、其他传感器

---

### 3.4 UART调试接口

```
PB1 → UART_TX → 调试串口RX (连接USB转串口模块)
PB2 → UART_RX → 调试串口TX (连接USB转串口模块)
```

**UART参数**：
- 波特率：9600 - 921600 bps
- 数据位：8位
- 停止位：1位
- 校验：无/奇/偶

---

### 3.5 控制信号

```
PD0 → 急停按钮 → 外部中断输入（低电平触发）
PD1 → 状态LED → 指示运行状态
```

---

### 3.6 时钟系统

```
Pin 19 → XTAL → 24MHz晶振输入
Pin 20 → XTAL → 24MHz晶振输出
```

**晶振参数**：
- 频率：24MHz
- 精度：±20ppm
- 负载电容：12-22pF（典型18pF）

---

### 3.7 烧录接口

```
Pin 21 → SWS → Telink单线调试接口
Pin 22 → RESET → 复位按钮（低电平有效）
```

**烧录工具**：
- Telink BDT (Burning and Debugging Tool)
- Telink JTAG/SWD调试器
- USB转串口模块（配合Bootloader）

### 4.1 电源引脚

## 六、模块使用说明

### 6.1 模块状态确认

由于您购买的模块"开机可反复擦洗"，说明：
- ✅ Flash已解锁，可重新烧录
- ✅ 没有读保护
- ✅ 可以使用Telink BDT工具烧录

### 6.2 烧录步骤

```
1. 连接烧录器
   ├─ SWS (Pin 21) → Telink BDT SWS
   ├─ RESET (Pin 22) → Telink BDT RESET
   ├─ VCC (Pin 23, 24) → 3.3V
   └─ GND (Pin 25-28) → GND

2. 打开Telink BDT工具

3. 选择芯片型号：TLSR8269

4. 加载固件文件（.bin）

5. 点击"Download"按钮

6. 等待烧录完成
```

### 6.3 验证烧录

```
1. 断开烧录器
2. 重新上电
3. 观察状态LED（PD1）
4. 使用UART调试查看输出
```

## 八、注意事项

### 8.1 焊接注意事项

1. **温度控制**：烙铁温度≤350°C，焊接时间<3秒
2. **防静电**：佩戴防静电手环，工作台铺防静电垫
3. **散热焊盘**：底部散热焊盘需接地，建议打9个过孔
4. **引脚对齐**：QFN封装引脚在底部，注意对齐

### 8.2 调试注意事项

1. **电源电压**：确保3.3V±5%，纹波<50mV
2. **晶振检查**：用示波器检查24MHz波形
3. **复位电路**：确保RESET引脚有上拉电阻（10kΩ）
4. **烧录接口**：SWS引脚需上拉电阻（10kΩ）

### 8.3 医疗级注意事项

1. **隔离要求**：患者侧与控制侧完全隔离
2. **漏电流**：患者侧漏电流<10μA
3. **绝缘阻抗**：>10MΩ
4. **安全认证**：需通过IEC 60601-1认证
