# 医疗仪器电源设计规范

> **依据标准**：GB 9706.1-2020《医用电气设备 第1部分：基本安全和基本性能的通用要求》

---

## 一、医疗电源核心要求

### 1.1 安全分类

| 类型 | 说明 | 适用场景 |
|------|------|----------|
| **B型** | 患者接地，无电气隔离 | 不直接接触患者 |
| **BF型** | 患者浮地，有隔离 | 与患者导电连接 |
| **CF型** | 患者直接心脏连接 | 心脏应用 |

**本项目**：经颅脉冲刺激属于**BF型**（与患者头部皮肤接触）

### 1.2 关键参数要求

| 参数 | 要求 | 说明 |
|------|------|------|
| **隔离耐压** | ≥3000V AC / 4242V DC | 患者电路与地之间 |
| **漏电流** | <100µA (正常) / <500µA (故障) | BF型要求 |
| **接地电阻** | <0.1Ω | 保护接地 |
| **绝缘电阻** | >50MΩ | 患者电路与地之间 |

## 二、电源架构设计

### 2.1 推荐架构（本项目）

```
输入电源 (5V USB 或 3.7V锂电池)
    │
    ├─[保险丝 F1 500mA]─────────────┐
    │                               │
    ├─[TVS管 5V]────────────────────┤ 过压保护
    │                               │
    ├─[共模电感]────────────────────┤ EMI滤波
    │                               │
    ▼                               ▼
┌─────────────┐             ┌─────────────┐
│   控制电源   │             │  隔离DC-DC   │
│  (非隔离侧)  │             │  (患者侧)    │
│             │             │             │
│  AMS1117    │             │  B0505S-1W  │
│  3.3V/1A   │             │  3000V隔离   │
│             │             │             │
│  → 蓝牙MCU  │             │  → 脉冲输出  │
│  → LED指示  │             │  → 电极驱动  │
│  → 急停电路  │             │  → 电流检测  │
└─────────────┘             └─────────────┘
     GND                        ISOGND
     (系统地)                    (隔离地)
                                   │
                              单点连接
```

### 2.2 隔离要求

**必须满足**：
- 患者电路（电极、脉冲输出）与控制系统完全隔离
- 隔离电压 ≥ 3000V AC（50Hz，1分钟）
- 爬电距离 ≥ 4mm（基本绝缘）
- 电气间隙 ≥ 2.5mm（基本绝缘）

## 三、详细电路设计

### 3.1 输入保护电路

```
    USB 5V 或 电池 3.7V
              │
              ├─[保险丝 F1]
              │   500mA 自恢复
              │   (过流保护)
              │
              ├─[TVS管 D1]
              │   SMBJ5.0A
              │   (过压保护，5V)
              │
              ├─[压敏电阻 RV1]
              │   5V 压敏
              │   (浪涌保护)
              │
              ├─[共模电感 L1]
              │   10mH
              │   (EMI滤波)
              │
              ├─[电容 C1]
              │   10µF/10V
              │   (输入滤波)
              │
              ▼
           5V_BUS
```

**器件选择**：
| 位号 | 器件 | 型号 | 参数 |
|------|------|------|------|
| F1 | 保险丝 | SMD1206-500mA | 500mA，自恢复 |
| D1 | TVS管 | SMBJ5.0A | 5V，600W峰值 |
| RV1 | 压敏电阻 | 5D470K | 47V，5mm |
| L1 | 共模电感 | ACM2012-900-2P | 10mH，0.5A |
| C1 | 电容 | 0805 10µF/10V | X5R |

### 3.2 控制电路电源（非隔离）

```
    5V_BUS
      │
      ├─[电容 C2]
      │   10µF/10V
      │
      ▼
   ┌─────────┐
   │ AMS1117 │
   │ 3.3V    │  ← 线性LDO，低噪声
   │ SOT-223 │
   └────┬────┘
        │
        ├─[电容 C3]──┬─── 3.3V_CTRL
        │   10µF     │    (控制电路电源)
        │            │
        ├─[电容 C4]  │
        │   100nF    │    (高频去耦)
        │            │
        └────────────┘
             │
            GND
```

**器件选择**：
| 位号 | 器件 | 型号 | 参数 |
|------|------|------|------|
| U2 | LDO | AMS1117-3.3 | 3.3V/1A，SOT-223 |
| C2 | 电容 | 0805 10µF/10V | 输入滤波 |
| C3 | 电容 | 0805 10µF/10V | 输出滤波 |
| C4 | 电容 | 0603 100nF/16V | 高频去耦 |

**注意**：
- AMS1117压差大时效率低，但噪声小
- 如果电池供电，建议使用DC-DC（如TPS62203）提高效率

### 3.3 隔离电源（患者电路）

```
    5V_BUS
      │
      ├─[电容 C5]
      │   10µF/10V
      │   (输入滤波)
      │
      ▼
   ┌─────────┐
   │B0505S-1W│  ← 隔离DC-DC模块
   │         │     3000V隔离
   │ 5V → 5V │     1W功率
   │         │
   └────┬────┘
        │
        ├─[电容 C6]──┬─── 5V_ISO
        │   10µF     │    (隔离电源输出)
        │            │
        ├─[电容 C7]  │
        │   100nF    │    (高频去耦)
        │            │
        └────────────┘
             │
           ISOGND
        (隔离地，单点连接系统地)
```

**器件选择**：
| 位号 | 器件 | 型号 | 参数 |
|------|------|------|------|
| U3 | 隔离DC-DC | B0505S-1W | 5V→5V，3000V隔离 |
| C5 | 电容 | 0805 10µF/10V | 输入滤波 |
| C6 | 电容 | 0805 10µF/10V | 输出滤波 |
| C7 | 电容 | 0603 100nF/16V | 高频去耦 |

**替代方案**：
- B0503.3S-1W：直接输出3.3V，减少一级LDO
- B1212S-1W：如果输入是12V

### 3.4 患者侧LDO（可选）

如果使用B0505S-1W（输出5V），需要额外LDO：

```
    5V_ISO
      │
      ▼
   ┌─────────┐
   │ AMS1117 │
   │ 3.3V    │  ← 患者侧LDO
   │ SOT-223 │
   └────┬────┘
        │
        ├─[电容 C8]──┬─── 3.3V_ISO
        │   10µF     │    (患者电路电源)
        │            │
        ├─[电容 C9]  │
        │   100nF    │
        │            │
        └────────────┘
             │
           ISOGND
```

**建议**：直接使用B0503.3S-1W（输出3.3V），省去此级LDO。

## 四、关键设计要点

### 4.1 隔离设计

**必须做到**：
1. **电气隔离**：患者电路与控制系统完全隔离
2. **物理隔离**：PCB上隔离带≥3mm
3. **单点接地**：ISOGND与GND单点连接

**隔离测试**：
- 耐压测试：3000V AC，1分钟，漏电流<1mA
- 绝缘电阻：>50MΩ（500V DC）

### 4.2 漏电流控制

**BF型设备要求**：
- 正常状态：漏电流 < 100µA
- 故障状态：漏电流 < 500µA

**措施**：
1. 使用隔离DC-DC
2. 光耦隔离所有患者侧信号
3. 减少患者侧对地电容

### 4.3 EMI/EMC设计

**要求**：符合YY 0505-2012（医用电气设备电磁兼容）

**措施**：
1. **输入滤波**：共模电感 + X电容 + Y电容
2. **屏蔽**：患者电路区域铺铜接地
3. **去耦**：每个芯片电源引脚旁100nF电容
4. **走线**：PWM信号远离敏感电路

### 4.4 电池供电设计

如果使用18650锂电池：

```
    18650电池 (3.7V)
         │
         ├─[保护板]──────────┐
         │  (过充/过放/短路)  │
         │                   │
         ▼                   ▼
      ┌─────────┐      ┌─────────┐
      │ 充电管理 │      │ 升压DC-DC│
      │ TP4056  │      │ MT3608  │
      │ (USB充电)│      │ 3.7V→5V │
      └─────────┘      └────┬────┘
                            │
                         5V_BUS
                            │
              ┌─────────────┼─────────────┐
              │             │             │
              ▼             ▼             ▼
         ┌────────┐   ┌────────┐   ┌────────┐
         │AMS1117 │   │B0505S  │   │充电指示│
         │3.3V    │   │隔离DC-DC│   │LED    │
         └────────┘   └────────┘   └────────┘
```

**器件选择**：
| 功能 | 器件 | 型号 |
|------|------|------|
| 充电管理 | TP4056 | 1A线性充电 |
| 升压 | MT3608 | 3.7V→5V，2A |
| 电池保护 | DW01+FS8205A | 过充/过放/短路 |

## 五、电源时序

### 5.1 上电时序

```
时间(ms)  0     10    20    30    40    50
          │     │     │     │     │     │
5V输入    ──────┬─────┬─────┬─────┬─────┬───
              上升沿
              │
3.3V控制   ───┴─────┬─────┬─────┬─────┬───
                  10ms后稳定
                  │
3.3V隔离   ───────┴─────┬─────┬─────┬─────
                      20ms后稳定
                      │
芯片复位   ───────────┴─────┬─────┬─────
                          释放复位
                          │
系统运行   ─────────────────┴─────────────
```

**要求**：
- 控制电源先上电
- 隔离电源后上电
- 芯片复位保持≥20ms

### 5.2 掉电时序

```
时间(ms)  0     10    20    30    40    50
          │     │     │     │     │     │
5V输入    ──────┴─────┴─────┴─────┴─────┴───
              下降沿
              │
芯片复位   ───┬─────┴─────┴─────┴─────┴───
            立即复位
            │
3.3V隔离   ─┴─────┴─────┴─────┴─────┴─────
          快速放电
          │
3.3V控制 ─┴─────┴─────┴─────┴─────┴───────
          快速放电
```

**要求**：
- 掉电时立即复位芯片
- 防止异常输出

## 六、保护电路

### 6.1 过流保护

```
    5V_BUS
      │
      ├─[保险丝 F1]
      │   500mA 自恢复
      │
      ├─[电流检测电阻]
      │   0.1Ω
      │
      ▼
   ┌─────────┐
   │ 比较器   │  ← 过流检测
   │ LM393   │
   └────┬────┘
        │
        └─► 过流信号 → 关闭输出
```

### 6.2 过压保护

```
    5V_BUS
      │
      ├─[TVS管 D1]
      │   SMBJ5.0A
      │   (钳位电压 9.2V)
      │
      ├─[稳压管 D2]
      │   5.6V
      │   (过压检测)
      │
      ▼
   ┌─────────┐
   │ 比较器   │  ← 过压检测
   │ LM393   │
   └────┬────┘
        │
        └─► 过压信号 → 关闭输出
```

### 6.3 反接保护

```
    输入+
      │
      ├─[二极管 D3]
      │   SS34 (肖特基)
      │   (反接保护)
      │
      ▼
   5V_BUS
      │
      ├─[MOS管 Q1]
      │   SI2301 (P沟道)
      │   (反接保护，更低压降)
      │
      ▼
   后续电路
```

| 测试项目 | 测试条件 | 要求 |

| 测试项目 | 测试条件 | 要求 |
|---------|---------|------|
| 高温工作 | +40℃，满载，4小时 | 无异常 |

## 九、注意事项

### 9.1 设计注意
1. **隔离距离**：患者侧与控制侧≥3mm
2. **爬电距离**：沿面距离≥4mm
3. **电气间隙**：空气距离≥2.5mm
4. **单点接地**：ISOGND与GND单点连接

### 9.2 生产注意
1. **清洗**：PCB清洗后烘干，防止漏电
2. **涂覆**：患者侧涂三防漆
3. **测试**：100%耐压测试

### 9.3 使用注意
1. **接地**：确保设备可靠接地
2. **检查**：每次使用前检查电极
3. **异常**：立即停止使用，检查故障
