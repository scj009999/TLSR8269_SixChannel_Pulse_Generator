### 2.2 布局优化

#### 电源布局优化
```
原布局问题：
- 稳压器远离输入连接器
- 去耦电容距离芯片较远

优化方案：
- U2 (AMS1117) 移动到 J1 附近
- C1-C3 紧贴 U2 放置
- C7-C14 (去耦电容) 紧贴 U1 每个电源引脚
```

#### 晶振布局优化
```
原布局问题：
- 晶振距离芯片较远
- 下方有走线

优化方案：
- Y1 移动到 U1 左侧 5mm 内
- 下方禁止走线（完整地平面）
- C4,C5 对称放置，距离晶振 <3mm
```

#### PWM输出布局优化
```
原布局问题：
- 6通道走线长度不等
- 无串联电阻

优化方案：
- 6通道走线等长（误差 <2mm）
- 添加 R11-R16 (33Ω) 串联电阻
- 走线间距 >0.3mm，避免串扰
```

## 五、关键区域布局要求

### 5.1 天线区域
```
位置：板右侧边缘，X=95-100mm, Y=30-50mm
要求：
  - 区域大小：10mm × 20mm
  - 禁止放置元件
  - 禁止走线（包括底层）
  - 禁止铺铜
  - 边缘保留 2mm 净空
```

### 5.2 晶振区域
```
位置：U1 左侧，X=75-85mm, Y=55-65mm
要求：
  - 晶振下方禁止走线
  - 周围 3mm 内禁止高速信号
  - 负载电容对称放置
  - 走线尽量短且等长
```

### 5.3 电源区域
```
位置：左上角，X=20-40mm, Y=65-80mm
要求：
  - 稳压器靠近输入
  - 输入/输出电容紧贴稳压器
  - 电源走线短而粗
  - 去耦电容回路最小
```

### 5.4 光耦隔离区域
```
位置：右侧中部，X=80-95mm, Y=40-60mm
要求：
  - 光耦两侧间距 >2.5mm
  - 初级/次级走线不交叉
  - 隔离槽或爬电距离满足要求
  - 高压侧走线远离低压侧
```

## 六、布线顺序建议

### 6.1 布线优先级
```
1. 地平面（优先完成）
2. 电源平面
3. 晶振走线
4. 天线走线
5. PWM输出走线
6. 高速信号（I2C/UART）
7. 一般信号
8. 测试点连接
```

### 6.2 布线注意事项
1. **先布关键信号**：晶振、天线、PWM
2. **避免直角**：所有走线用45°或圆弧
3. **差分对等长**：I2C的SCL/SDA等长
4. **回流路径最小**：信号下方有完整回流地
5. **避免跨分割**：信号不跨越地平面分割

## 十一、常见问题

### Q1: 天线匹配网络如何调整？
**A**: 使用网络分析仪测量，调整 C16/C17 使驻波比 <1.5

### Q2: 光耦隔离间距不够怎么办？
**A**: 增加开槽或改用更大封装的光耦

### Q3: 去耦电容数量是否可以减少？
**A**: 不建议，每个电源引脚都需要去耦电容

### Q4: 测试点是否可以省略？
**A**: 不建议，测试点对调试至关重要
