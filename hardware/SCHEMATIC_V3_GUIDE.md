## 三、电路模块详解

### 3.1 电源管理模块

```
J1 (PWR_IN)          F1              U2 (AMS1117-3.3)
┌─────┐            ┌─────┐         ┌──────────┐
│ 5V  │────────────│500mA│────────►│  VI    VO │──────► +3.3V
│ GND │────────────│     │         │    GND   │        │
└─────┘            └─────┘         └──────────┘        │
                                                      │
        C1 (10uF) ─────┬───── C2 (100nF) ─────┬─────┘
                       │                       │
                      GND                     GND
        C3 (10uF) ─────┘
```

**元件清单**：
| 位号 | 元件 | 参数 | 封装 |
|------|------|------|------|
| J1 | 电源连接器 | 5V USB输入 | 1x2 2.54mm |
| F1 | 保险丝 | 500mA | 1206 |
| U2 | 稳压器 | AMS1117-3.3 | SOT-223 |
| C1 | 输入电容 | 10uF | 1206 |
| C2 | 输出电容 | 100nF | 0603 |
| C3 | 输出电容 | 10uF | 1206 |

**设计要点**：
- 输入5V（USB或适配器）
- 输出3.3V ±1%
- 最大电流1A
- 压差<1.3V @ 1A

| 档位 | 电阻值 | ADC电压 | 强度 |

**注意**：最大输出限制在80%，保留20%安全余量

### 3.6 光耦隔离电路（×6路）

```
    控制侧 (系统地)              隔离带              患者侧 (隔离地)
    ┌─────────────┐            ┌─────┐            ┌─────────────┐
    │             │            │     │            │             │
    │ PWM0 (PA0)  │───R9───────┤PC817├────R10─────┤───► CH0+    │
    │             │  330Ω      │ U4  │  100Ω      │             │
    │             │            │     │            │             │
    │    GND      │────────────┤     ├────────────┤───► CH0-    │
    │             │            │     │            │             │
    └─────────────┘            └─────┘            └─────────────┘
    
    重复6次 (U4-U9, R9-R20, R10-R15)
    PWM1-PWM5 → CH1-CH5
```

**元件清单（每路）**：
| 位号 | 元件 | 参数 | 封装 |
|------|------|------|------|
| U4-U9 | 光耦 | PC817 | SMDIP-4 |
| R9-R14 | 输入限流 | 330Ω | 0603 |
| R15-R20 | 输出限流 | 100Ω | 0603 |

**隔离参数**：
- 隔离电压：≥2500Vrms
- 电流传输比：50-600%
- 响应时间：4μs

## 五、PCB布局建议

### 5.1 布局分区

```
┌─────────────────────────────────────────┐
│              电源输入区                   │
│    J1 ── F1 ── U2(AMS1117) ── C1-C3    │
├─────────────────────────────────────────┤
│                                         │
│    ┌─────────────────────────┐         │
│    │      U1 (CR8269)        │         │
│    │    主控芯片区域          │         │
│    │                         │         │
│    │  Y1(晶振)  SW1(复位)    │         │
│    │  C4-C5     R1           │         │
│    └─────────────────────────┘         │
│                                         │
├─────────────────────────────────────────┤
│              控制输入区                   │
│    RV1(电位器)  SW2(急停)  D1(LED)     │
├─────────────────────────────────────────┤
│              隔离边界                     │
│    ═══════════════════════════════      │
│    间隙 ≥ 3mm  无铜  无走线              │
├─────────────────────────────────────────┤
│              患者侧区域                   │
│    U4-U9(光耦) ── R9-R20 ── J3(电极)   │
│    J4(隔离电源)                         │
└─────────────────────────────────────────┘
```

### 5.2 关键布局要点

1. **晶振靠近芯片**：走线 < 20mm
2. **去耦电容靠近电源引脚**：C7-C8靠近Pin 23-24
3. **光耦跨接隔离带**：控制侧和患者侧完全分离
4. **隔离电源独立**：J4提供独立的患者侧电源
5. **电极输出远离数字信号**：防止干扰

## 六、安全设计

### 6.1 电气安全

| 项目 | 设计值 | 标准 |
|------|--------|------|
| 隔离耐压 | ≥2500Vrms | IEC 60601-1 |
| 漏电流 | <10μA | IEC 60601-1 |
| 绝缘阻抗 | >10MΩ | IEC 60601-1 |
| 输出电流限制 | ≤2mA | 设计约束 |
| 输出电压限制 | ≤24V | 设计约束 |

### 6.2 软件保护

1. **电流监测**：INA219实时检测，超限自动切断
2. **阻抗检测**：启动前检测电极阻抗，异常报警
3. **超时保护**：单次治疗不超过30分钟
4. **急停功能**：硬件中断，立即切断所有输出

## 七、使用说明

### 7.1 初次上电

1. 连接5V电源到J1
2. 连接电极到J3
3. 打开电源开关
4. 观察D1状态LED：
   - 常亮：正常工作
   - 闪烁：故障/报警
   - 熄灭：未工作

### 7.2 强度调节

1. 旋转RV1电位器选择档位：
   - 1档：关闭
   - 2档：弱（20%）
   - 3档：中（40%）
   - 4档：强（60%）
   - 5档：最强（80%）

2. 也可通过软件UART命令调节

### 7.3 急停操作

- **按下SW2**：立即切断所有PWM输出
- **松开SW2**：恢复工作（需软件确认）

## 八、故障排查

| 现象 | 可能原因 | 解决方法 |
|------|----------|----------|
| 无输出 | 保险丝熔断 | 检查F1，更换500mA保险丝 |
| LED不亮 | 电源故障 | 检查U2输出3.3V |
| 输出不稳定 | 晶振未起振 | 检查Y1、C4、C5 |
| 电流异常 | 电极接触不良 | 检查J3连接 |
| 无法烧录 | SWS连接错误 | 检查J2接线 |
