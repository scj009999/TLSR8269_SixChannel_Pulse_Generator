# TLSR8269F512ET32 引脚定义（QFN32）

> ⚠️ **重要提示**：以下引脚分配基于Telink官方资料整理，**请务必以最新版Datasheet为准**。

## 封装信息

- **封装类型**：QFN32
- **封装尺寸**：5mm × 5mm
- **引脚间距**：0.5mm
- **散热焊盘**：底部中心（需接地）

## 功能分组

### PWM输出（6路）
```
PA0 → PWM0 → CH0
PA1 → PWM1 → CH1
PA2 → PWM2 → CH2
PA3 → PWM3 → CH3
PA4 → PWM4 → CH4
PA5 → PWM5 → CH5
```

### ADC输入（6路）
```
PC0 → ADC0 → 电池电压监测
PC1 → ADC1 → 电流检测 CH0
PC2 → ADC2 → 电流检测 CH1
PC3 → ADC3 → 电流检测 CH2
PC4 → ADC4 → 电流检测 CH3
PC5 → ADC5 → 电流检测 CH4
```

**注意**：QFN32只有6路ADC，如果需要6路电流检测+电池监测，需要：
- 方案1：省略电池监测，6路全部用于电流检测
- 方案2：使用INA219的I2C接口，不占用ADC
- 方案3：使用外部ADC芯片（如ADS1115）

### I2C接口
```
PB0 → I2C_SCL → INA219 SCL
PB3 → I2C_SDA → INA219 SDA
```

### UART调试
```
PB1 → UART_TX → 调试串口RX
PB2 → UART_RX → 调试串口TX
```

### 控制信号
```
PD0 → 急停按钮（外部中断）
PD1 → 状态LED
```

### 时钟
```
Pin 19 → XTAL → 24MHz晶振输入
Pin 20 → XTAL → 24MHz晶振输出
```

### 烧录
```
Pin 21 → SWS → Telink烧录器
Pin 22 → RESET → 复位按钮
```

## PCB布局建议

### 去耦电容布局
```
       VCC (Pin 23, 24)
         │
    ┌────┴────┐
    │ 100nF   │  ← 尽量靠近引脚23, 24
    │ 陶瓷    │
    └────┬────┘
         │
        GND (Pin 25-28)
```

### 晶振布局
```
    ┌─────────────────┐
    │                 │
    │   TLSR8269      │
    │                 │
    │  Pin 19 ────────┼─── 晶振 ──── Pin 20
    │   XTAL          │    24MHz      XTAL
    │                 │
    └─────────────────┘
         │
    ┌────┴────┐
    │  22pF   │
    │  22pF   │
    └────┬────┘
        GND
```

### 光耦布局
```
    控制侧（系统地）        隔离带        患者侧（隔离地）
    ┌──────────┐          ┌───┐         ┌──────────┐
    │          │          │   │         │          │
    │ PA0 ─────┼──────────┤PC817├───────┼──── 100Ω ─┼──► CH0+
    │          │          │   │         │          │
    └──────────┘          └───┘         └──────────┘
```

## 注意事项

1. **引脚确认**：请务必下载最新版Datasheet确认引脚定义
2. **散热焊盘**：QFN32底部有散热焊盘，需接地并打过孔
3. **去耦电容**：每个VCC引脚旁至少一个100nF电容
4. **晶振走线**：尽量短，下方不走其他信号线
5. **隔离距离**：光耦下方保持≥3mm间距
