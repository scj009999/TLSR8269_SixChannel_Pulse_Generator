```
    VIN (5V或3.3V)
      │
      ├─[10µF]──┬─── GND
      │         │

```
              VCC (3.3V)

### 5. 烧录接口 (SWS)

```
    烧录器接口:
    
    ┌─────────┐
    │  VCC    │─── 3.3V
    │  GND    │─── GND
    │  SWS    │─── SWS (Pin 31)
    │  RESET  │─── RESET
    └─────────┘
    
    注意：Telink烧录器使用单线调试(SWS)
```

### 6. 脉冲输出接口

```
    输出端子 (6路PWM输出):
    
    ┌─────────────────────────┐
    │  CH0  │  PA0  │  PWM0   │
    │  CH1  │  PA1  │  PWM1   │
    │  CH2  │  PA2  │  PWM2   │
    │  CH3  │  PA3  │  PWM3   │
    │  CH4  │  PA4  │  PWM4   │
    │  CH5  │  PA5  │  PWM5   │
    │  GND  │       │  地线   │
    │  VCC  │       │  3.3V   │
    └─────────────────────────┘
    
    输出特性：
    - 高电平：3.3V
    - 低电平：0V
    - 驱动能力：约8mA/引脚
    - 建议外接驱动电路用于大功率负载
```

### 7. 调试串口

```
    UART接口 (可选):
    
    ┌─────────┐
    │  TX     │─── PB1 (Pin 8)  → 连接到USB转TTL的RX
    │  RX     │─── PB2 (Pin 9)  ← 连接到USB转TTL的TX
    │  GND    │─── GND
    └─────────┘
    
    波特率：115200
    数据位：8
    停止位：1
    校验位：无
```

## PCB布局建议

### 顶层布局

```
┌────────────────────────────────────────┐
│  ┌──────────────┐                      │
│  │   TLSR8269   │    ┌─────────────┐  │
│  │              │    │   晶振      │  │
│  │  PA0-PA5     │    │   24MHz     │  │
│  │  (左侧输出)   │    └─────────────┘  │
│  │              │                      │
│  │  PB1-PB2     │    ┌─────────────┐  │
│  │  (右侧调试)   │    │   LDO       │  │
│  │              │    │   3.3V      │  │
│  └──────────────┘    └─────────────┘  │
│                                        │
│  [CH0] [CH1] [CH2] [CH3] [CH4] [CH5]  │
│   ○    ○    ○    ○    ○    ○         │
│                                        │
│  [GND] [VCC] [TX]  [RX]  [SWS] [RST] │
│   ○    ○    ○    ○    ○    ○         │
└────────────────────────────────────────┘
```

### 布局要点

1. **去耦电容**: 尽量靠近芯片VCC引脚放置
2. **晶振**: 靠近XTAL引脚，走线尽量短
3. **PWM输出**: 等长走线，减少信号 skew
4. **地线**: 大面积铺地，减少EMI
5. **电源**: 星型拓扑，避免压降

## 注意事项

1. **防静电**: TLSR8269为CMOS器件，注意ESD防护
2. **电源顺序**: 确保3.3V稳定后再启动芯片
3. **烧录**: 首次烧录需要Telink专用烧录器
4. **散热**: 正常工作电流约40mA，一般不需额外散热
