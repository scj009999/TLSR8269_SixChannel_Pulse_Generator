## 二、生产流程（本项目）

### 2.1 第一步：DFM分析（已完成）

**使用华秋DFM软件**：
1. 导入KiCad设计文件
2. 运行"一键分析"
3. 查看分析报告
4. 根据建议修改设计
5. 重复直到无错误

**关键检查项**：
- [ ] 线宽/线距 ≥ 4mil
- [ ] 孔径 ≥ 0.2mm
- [ ] 隔离距离 ≥ 3mm（医疗要求）
- [ ] 丝印清晰可读
- [ ] 测试点完整

### 2.2 第二步：PCB打样

#### 下单流程

1. **登录华秋官网**
   - 网址：https://www.hqpcb.com/
   - 使用已有账号登录

2. **上传Gerber**
   - 点击"PCB下单"
   - 上传Gerber压缩包
   - 系统自动解析层数、尺寸

3. **选择参数**

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| **板材** | FR-4 | 标准玻纤板 |
| **层数** | 4层 | 控制层+电源层+地层+患者层 |
| **板厚** | 1.6mm | 标准厚度 |
| **铜厚** | 1oz | 标准铜厚 |
| **阻焊** | 绿色 | 标准颜色 |
| **丝印** | 白色 | 清晰可读 |
| **表面处理** | 沉金(ENIG) | 医疗级，抗氧化 |
| **最小线宽** | 4mil | 工艺能力 |
| **最小孔径** | 0.2mm | 工艺能力 |

4. **确认报价**
   - 系统自动计算价格
   - 4层板5片约¥100-150

5. **提交订单**
   - 确认收货地址
   - 选择快递方式
   - 在线支付

#### 预计时间
- PCB打样：5-7个工作日
- 快递：2-3天
- **总计：7-10天收到样品**

### 2.3 第三步：SMT贴片（可选）

如果需要华秋代焊接：

#### 准备BOM

使用华秋DFM一键导出BOM：
```
1. 打开华秋DFM
2. 点击"一键输出"
3. 选择"BOM清单"
4. 保存为Excel
```

#### BOM格式

| 序号 | 位号 | 型号 | 封装 | 数量 | 备注 |
|------|------|------|------|------|------|
| 1 | U1 | TLSR8269F512ET32 | QFN32 | 1 | 主控芯片 |
| 2 | U2 | AMS1117-3.3 | SOT-223 | 1 | LDO |
| 3 | U3 | B0505S-1W | SIP-4 | 1 | 隔离DC-DC |
| 4 | U4-U9 | PC817 | DIP-4 | 6 | 光耦 |
| 5 | U10 | INA219 | SOT-23-8 | 1 | 电流检测 |
| ... | ... | ... | ... | ... | ... |

#### 下单流程

1. 登录华秋SMT：https://smt.hqpcb.com/
2. 上传BOM和坐标文件
3. 选择"代采购元器件"或"自供元器件"
4. 确认贴片费用（按焊点数计费）
5. 提交订单

#### 预计费用
- 贴片费：约¥0.02-0.05/点
- 本项目约200-300点
- **贴片费：约¥50-100**

#### 预计时间
- 元器件采购：3-5天
- SMT贴片：2-3天
- **总计：5-8天**

### 2.4 第四步：3D外壳设计

收到PCB样品后，测量实际尺寸，设计外壳。

#### 外壳设计流程

```
1. 测量PCB尺寸（长×宽×高）
2. 确定接口位置（USB、电极、按钮）
3. 设计外壳3D模型
4. 导出STL文件
5. 华秋3D打印或CNC加工
```

#### 外壳要求

| 项目 | 要求 | 说明 |
|------|------|------|
| **材料** | ABS/PC | 医用级塑料 |
| **颜色** | 白色/浅灰 | 医疗设备常用 |
| **表面处理** | 磨砂 | 防滑、美观 |
| **防护等级** | IP54 | 防尘防水溅 |
| **电极接口** | 6路 | 香蕉插座或专用接口 |
| **USB接口** | 1路 | 充电/调试 |
| **按钮** | 2个 | 电源+急停 |
| **LED窗口** | 3个 | 状态指示 |
| **固定方式** | 螺丝/卡扣 | 便于维修 |

#### 3D建模软件推荐

| 软件 | 类型 | 费用 | 难度 |
|------|------|------|------|
| **Fusion 360** | 专业 | 免费（个人版） | 中等 |
| **SolidWorks** | 专业 | 收费 | 较难 |
| **Tinkercad** | 在线 | 免费 | 简单 |
| **FreeCAD** | 开源 | 免费 | 中等 |

#### 华秋3D打印服务

1. 登录华秋3D：https://3d.hqpcb.com/
2. 上传STL文件
3. 选择材料（ABS/PLA/树脂）
4. 确认报价
5. 提交订单

**预计费用**：
- 外壳约50-100g
- ABS材料约¥0.5-1/g
- **3D打印费：约¥50-100**

## 五、质量控制

### 5.1 PCB检查

收到PCB后检查：
- [ ] 尺寸是否正确
- [ ] 孔位是否对齐
- [ ] 线宽是否符合设计
- [ ] 丝印是否清晰
- [ ] 阻焊是否完整
- [ ] 表面是否有划痕

### 5.2 焊接检查

- [ ] 所有元件焊接牢固
- [ ] 无短路、虚焊
- [ ] 极性元件方向正确
- [ ] 芯片引脚无连锡

### 5.3 功能测试

- [ ] 电源电压3.3V±5%
- [ ] 隔离耐压测试
- [ ] 漏电流测试
- [ ] PWM输出正常
- [ ] 电流检测准确
- [ ] 蓝牙连接稳定
- [ ] 急停功能正常

### 5.4 外壳检查

- [ ] 尺寸匹配
- [ ] 接口对齐
- [ ] 按钮灵活
- [ ] LED可见
- [ ] 无尖锐边缘

## 六、问题处理

### 6.1 PCB问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 尺寸错误 | 设计单位错误 | 检查mm/mil设置 |
| 孔径不对 | 钻孔文件错误 | 重新导出Gerber |
| 线宽不足 | 工艺能力限制 | 加大线宽 |
| 短路 | 设计错误 | 检查DRC |

### 6.2 焊接问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 虚焊 | 温度不足 | 提高焊接温度 |
| 短路 | 焊锡过多 | 吸锡带清理 |
| 芯片损坏 | ESD静电 | 佩戴防静电手环 |

### 6.3 外壳问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 尺寸偏差 | 打印收缩 | 预留余量 |
| 接口不对 | 测量错误 | 重新测量PCB |
| 强度不足 | 材料选择 | 改用更厚材料 |
