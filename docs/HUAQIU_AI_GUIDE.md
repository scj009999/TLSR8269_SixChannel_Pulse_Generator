# 华秋小助手（KiCad Copilot）使用指南

> **说明**：华秋小助手是华秋电子2026年3月推出的国内首款深度融合大模型的AI EDA工具，集成在华秋DFM中。

---

## 一、软件下载与安装

### 1.1 下载华秋DFM

**官网下载**：https://dfm.elecfans.com/

**下载步骤**：
1. 访问华秋DFM官网
2. 点击"免费下载"按钮
3. 选择Windows版本（支持Win7/10/11）
4. 下载安装包（约150MB）

### 1.2 安装

1. 双击安装包
2. 选择安装路径（建议默认）
3. 等待安装完成
4. 启动华秋DFM

### 1.3 注册登录

1. 打开华秋DFM
2. 点击右上角"登录"
3. 使用手机号注册/登录
4. 登录后即可使用AI功能

## 二、华秋小助手AI功能

### 2.1 功能介绍

华秋小助手（KiCad Copilot）主要功能：

| 功能 | 说明 | 适用场景 |
|------|------|----------|
| **智能交互** | 自然语言对话，理解设计意图 | 快速查询、设计建议 |
| **电路识别** | 拍照/上传识别电路图 | 分析现有电路 |
| **设计检查** | AI自动分析设计隐患 | DFM检查 |
| **优化建议** | 提供PCB优化方案 | 降低成本、提高良率 |
| **一键输出** | 自动生成Gerber/BOM/坐标 | 生产准备 |

### 2.2 启动华秋小助手

1. 打开华秋DFM
2. 导入或打开PCB文件
3. 点击右侧"AI助手"或"小助手"按钮
4. 进入AI对话界面

## 三、医疗电路设计应用

### 3.1 导入您的设计

**支持格式**：
- KiCad (.kicad_pcb)
- Altium (.pcbdoc)
- Gerber文件
- 立创EDA文件

**导入步骤**：
1. 点击"文件" → "导入"
2. 选择您的KiCad文件
3. 等待解析完成
4. 查看3D预览

### 3.2 使用AI检查医疗电路

**示例对话**：

```
您：请检查这个医疗电路的安全隐患

AI：正在分析您的PCB设计...

发现以下问题：
1. 【严重】隔离距离不足：光耦下方间距仅2.1mm，建议≥3mm
2. 【警告】电流检测电阻功率不足：1Ω/0603电阻仅0.1W，建议改用1206封装
3. 【建议】增加测试点：关键信号未添加测试点
4. 【优化】去耦电容距离过远：C11距离芯片15mm，建议<10mm

优化建议：
- 调整光耦位置，确保隔离带≥3mm
- 电流检测电阻改用1206封装或2512封装
- 在PWM输出、ADC输入添加测试点
- 将去耦电容靠近芯片VCC引脚
```

### 3.3 符合国家标准检查

**您可以让AI检查**：

```
您：请检查这个设计是否符合GB 9706.1-2020标准

AI：正在检查医疗电气安全标准...

【隔离检查】
- 隔离耐压：当前设计使用B0505S-1W（3000V隔离）✅ 符合
- 爬电距离：测量中... 建议≥4mm
- 电气间隙：测量中... 建议≥2.5mm

【漏电流检查】
- 患者电路隔离：光耦+DC-DC双重隔离 ✅
- 对地电容：建议<100pF

【接地检查】
- 保护接地：检测到接地符号 ✅
- 接地电阻：建议<0.1Ω

【建议】
1. 在隔离带添加"隔离栏"标识
2. 患者侧增加"BF型设备"标识
3. 添加高压警示标识
```

## 四、针对本项目的使用流程

### 4.1 第一步：导入原理图

1. 在KiCad中完成原理图设计
2. 导出网表（.net文件）
3. 在KiCad PCB Editor中导入网表
4. 保存为 .kicad_pcb 文件
5. 在华秋DFM中打开该文件

### 4.2 第二步：AI分析

```
您：这是一个经颅脉冲治疗仪的PCB，请检查医疗安全

AI：正在分析医疗电路...

【电源部分】
- 隔离DC-DC：B0505S-1W ✅
- 保险丝：500mA ✅
- TVS管：SMBJ5.0A ✅
- 建议：增加反向二极管防止反接

【隔离部分】
- 光耦：PC817 × 6 ✅
- 隔离距离：测量中...
- 建议：确保光耦下方无铜箔，间距≥3mm

【电流检测】
- INA219：I2C接口 ✅
- 采样电阻：建议1Ω/1% ✅

【优化建议】
1. 增加LED指示灯测试点
2. 添加版本号和日期丝印
3. 增加防静电标识
```

### 4.3 第三步：优化设计

根据AI建议：
1. 调整元件位置
2. 修改走线
3. 添加测试点
4. 完善丝印

### 4.4 第四步：DFM检查

1. 点击"一键分析"
2. 查看分析结果
3. 根据建议修改
4. 重新分析直到通过

### 4.5 第五步：输出生产文件

1. 点击"一键输出"
2. 选择输出格式：
   - Gerber文件
   - BOM清单
   - 坐标文件
3. 保存到指定目录

## 五、实用技巧

### 5.1 快速查询

```
您：AMS1117-3.3的推荐封装是什么？

AI：AMS1117-3.3推荐封装：
- SOT-223：散热较好，适合1A输出
- SOT-89：体积小，适合<500mA
- TO-252：散热最好，适合大电流

建议：本项目使用SOT-223，平衡散热和尺寸
```

### 5.2 成本优化

```
您：如何降低这个设计的成本？

AI：成本优化建议：

【BOM优化】
1. 电阻电容统一为0603封装，减少贴片费用
2. 光耦PC817可改用EL817，价格更低
3. 隔离DC-DC B0505S-1W可批量采购降低单价

【PCB优化】
1. 板厚从1.6mm改为1.0mm，节省材料费
2. 层数从4层改为2层（需确认信号完整性）
3. 拼板设计，提高利用率

预计节省：15-20%
```

### 5.3 医疗标准查询

```
您：BF型设备的漏电流要求是多少？

AI：根据GB 9706.1-2020：

【漏电流限值】
- B型设备：正常<100µA，故障<500µA
- BF型设备：正常<100µA，故障<500µA  
- CF型设备：正常<10µA，故障<50µA

【本项目】
经颅脉冲刺激属于BF型设备
- 正常状态漏电流应<100µA
- 故障状态漏电流应<500µA

【测试方法】
使用漏电流测试仪，施加额定电压的110%
```

## 六、常见问题

### Q1：华秋小助手收费吗？
**A**：华秋DFM基础功能永久免费，AI功能目前免费试用。

### Q2：支持哪些EDA软件？
**A**：支持KiCad、Altium Designer、PADS、立创EDA等。

### Q3：AI分析准确吗？
**A**：AI分析基于大量设计规则和工厂数据，建议作为参考，关键设计需人工确认。

### Q4：可以离线使用吗？
**A**：华秋DFM可以离线使用基础功能，AI功能需要联网。

### Q5：如何导出到嘉立创生产？
**A**：
1. 在华秋DFM中完成分析
2. 点击"一键输出"Gerber
3. 登录嘉立创官网
4. 上传Gerber文件下单
