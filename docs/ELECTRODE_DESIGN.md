# 头戴式电极设计与功率调节方案

> **说明**：针对帕金森经颅刺激，设计头戴式电极连接方案和功率调节方式。

---

## 一、头戴式电极设计

### 1.1 电极布局（国际10-20系统）

```
            鼻根
              │
    ┌─────────┼─────────┐
    │    Fp1  │  Fp2    │  ← 前额叶（认知功能）
    │         │         │
    │  F7  F3 │ F4  F8  │  ← 额叶
    │         │         │
    │    T3   │   T4    │  ← 颞叶
    │         │         │
    │  T5  P3 │ P4  T6  │  ← 顶叶
    │         │         │
    │    O1   │   O2    │  ← 枕叶（视觉）
    └─────────┼─────────┘
              │
            枕骨
```

### 1.2 六路电极对应脑区

| 通道 | 位置 | 脑区 | 功能 | 颜色标识 |
|------|------|------|------|----------|
| **CH1** | F3-F4 | 背外侧前额叶 | 运动计划、认知 | 红色 |
| **CH2** | C3-C4 | 初级运动皮层 | 运动控制 | 黄色 |
| **CH3** | P3-P4 | 顶叶联合区 | 感觉整合 | 绿色 |
| **CH4** | F7-F8 | 前额叶外侧 | 语言、执行 | 蓝色 |
| **CH5** | T3-T4 | 颞叶 | 听觉、记忆 | 白色 |
| **CH6** | O1-O2 | 枕叶 | 视觉处理 | 黑色 |

### 1.3 电极类型选择

| 类型 | 特点 | 适用 | 成本 |
|------|------|------|------|
| **银/氯化银电极** | 信号稳定，低噪声 | 科研级 | 高 |
| **不锈钢电极** | 耐用，易清洁 | 临床级 | 中 |
| **碳橡胶电极** | 柔软，舒适 | 家用 | 低 |
| **自粘电极片** | 方便，一次性 | 临时 | 低 |

**推荐**：碳橡胶电极（家用舒适）或不锈钢电极（耐用可清洁）

### 1.4 自制电极方案

#### 材料清单

| 材料 | 规格 | 数量 | 来源 |

| 碳橡胶片 | 20mm直径，3mm厚 | 12片 | 淘宝/京东 |
| 导电凝胶 | 医用级 | 1瓶 | 医疗器械店 |
| 硅胶导线 | 2芯屏蔽线，1.5m | 6条 | 电子市场 |
| 香蕉插头 | 4mm | 12个 | 电子市场 |

#### 制作步骤

```
1. 裁剪碳橡胶片为20mm圆片（12片）

3. 硅胶导线一端焊接香蕉插头
4. 导线另一端连接电极片
5. 用魔术贴固定电极到头带
6. 标记通道编号和颜色
```

## 二、功率调节方案对比

### 2.1 方案一：软件调节（推荐）

#### 实现方式
- **PWM占空比调节**：通过改变PWM占空比控制输出电流
- **电压调节**：通过DAC改变输出电压幅度
- **脉冲频率调节**：改变刺激频率

#### 优点
| 优点 | 说明 |
|------|------|
| **精确控制** | 数字控制，精度0.1% |
| **可编程** | 可设置多种刺激模式 |
| **安全保护** | 软件限流，过流保护 |
| **数据记录** | 可记录使用数据 |
| **远程调节** | 手机APP控制 |

#### 缺点
| 缺点 | 说明 |
|------|------|
| **需要调试** | 软件编程复杂 |
| **依赖电源** | 需要稳定供电 |
| **成本略高** | 需要DAC芯片 |

#### 电路设计

```
TLSR8269                    恒流源电路
┌─────────┐                ┌─────────────┐
│         │──PWM1 (PF2)───→│  运放       │

│         │──PWM2 (PF3)───→│  │  DAC  │  │
│         │                │  └───┬───┘  │
│         │──PWM3 (PF4)───→│      │      │
│         │                │  ┌───┴───┐  │
│         │──PWM4 (PF5)───→│  │  V-I  │  │
│         │                │  │ 转换  │  │
│         │──PWM5 (PA0)───→│  └───┬───┘  │
│         │                │      │      │
│         │──PWM6 (PA1)───→│  ┌───┴───┐  │
│         │                │  │ 电极  │  │
```

### 2.2 方案二：外接电位器

#### 实现方式
- **电位器分压**：用电位器调节输出电压
- **串联电阻**：改变限流电阻值

#### 优点
| 优点 | 说明 |
|------|------|
| **简单直观** | 旋钮调节，老人易用 |
| **成本低** | 仅需电位器 |
| **不依赖软件** | 硬件实现 |
| **可靠性高** | 无软件bug风险 |

#### 缺点
| 缺点 | 说明 |
|------|------|
| **精度低** | 模拟调节，精度约5% |
| **不可编程** | 无法设置复杂模式 |
| **无记录** | 无法记录使用数据 |
| **易误触** | 可能意外改变设置 |

#### 电路设计

```
                    电位器调节
                    ┌──────────┐
                    │   100Ω   │
                    │  ┌────┐  │
3.3V ───────────────┼──┤    ├──┼──→ 运放输入
                    │  │ 50Ω│  │
                    │  └────┘  │
                    │     ↑    │
                    │   旋钮   │
                    └──────────┘
```

## 四、电路实现

### 4.1 恒流源电路（单路）

```
                    VCC (3.3V)
                      │
                      R1 (100Ω)
                      │
PWM输入 ──┬───────────┤
          │           │
          │      ┌────┴────┐
          │      │  运放    │
          │      │  LM358   │
          │      │          │
          └─────→│  +       │
                 │     OUT  ├────→ 电极+
                 │          │      │
                 │  -       │      R_sense (10Ω)
                 └────┬─────┘      │
                      │            │
                      └────────────┤
                                   │
                              ┌────┴────┐
                              │  电极-   │
                              │  返回    │
                              └────┬────┘
                                   │
                              ┌────┴────┐
                              │  ADC检测  │
                              │  电流反馈 │
                              └─────────┘

电流计算公式：
I_out = V_pwm / R_sense

例如：
V_pwm = 1V, R_sense = 10Ω
I_out = 1V / 10Ω = 100mA（太大！）

修正：
R_sense = 1kΩ
I_out = 1V / 1kΩ = 1mA（合适）
```

## 五、软件实现

### 5.1 PWM配置

```c
// 六路PWM初始化
void pwm_init_all(void) {
    // 配置PWM时钟 1MHz
    pwm_set_clk(CLOCK_SYS_CLOCK_HZ, 1000000);
    
    // 六路PWM配置
    // CH1: PF2, CH2: PF3, CH3: PF4
    // CH4: PF5, CH5: PA0, CH6: PA1
    
    for (int i = 0; i < 6; i++) {
        pwm_set_cycle_and_duty(i, 1000, 0);  // 1kHz, 0%占空比
        pwm_start(i);
    }
}

// 设置输出强度 (0-100%)
void set_intensity(uint8_t ch, uint8_t percent) {
    if (percent > 100) percent = 100;
    uint16_t duty = (percent * 1000) / 100;  // 转换为duty值
    pwm_set_duty(ch, duty);
}
```

### 5.2 电流闭环控制

```c
// 目标电流 (mA)
float target_current[6] = {0.5, 0.5, 0.5, 0.5, 0.5, 0.5};

// 电流闭环控制
void current_control_loop(void) {
    for (int ch = 0; ch < 6; ch++) {
        // 读取实际电流
        float actual = ina219_read_current(ch);
        
        // PID计算
        float error = target_current[ch] - actual;
        float output = pid_calculate(ch, error);
        
        // 限制输出
        if (output > 100) output = 100;
        if (output < 0) output = 0;
        
        // 设置PWM
        set_intensity(ch, (uint8_t)output);
        
        // 安全检查
        if (actual > 2.0) {  // 超过2mA
            emergency_stop(ch);
            ble_send_alert("Overcurrent CH%d", ch);
        }
    }
}
```

### 5.3 蓝牙通信协议

```c
// 蓝牙命令格式
// 0xAA 0x55 CMD LEN DATA CRC

// 设置强度命令
// CMD: 0x01
// DATA: [CH] [INTENSITY]
// 例：设置CH1为50%
// 0xAA 0x55 0x01 0x02 0x01 0x32 CRC

// 读取状态命令
// CMD: 0x02
// 返回：[CH1_I][CH2_I][CH3_I][CH4_I][CH5_I][CH6_I]

// 急停命令
// CMD: 0xFF
// 立即停止所有输出
```

## 七、安全规范

### 7.1 使用禁忌

| 情况 | 说明 |
|------|------|
| **心脏起搏器** | 绝对禁忌，可能干扰 |
| **癫痫病史** | 可能诱发发作 |
| **脑部金属植入** | 电流集中风险 |
| **皮肤破损** | 感染风险 |
| **孕妇** | 安全性未验证 |
| **儿童** | 需医生指导 |

### 7.2 使用规范

1. **首次使用**：从最低强度开始
2. **逐渐增加**：每次增加不超过10%
3. **时间限制**：单次不超过30分钟
4. **皮肤检查**：使用前检查皮肤状况
5. **不适停止**：头晕、恶心立即停用

### 7.3 维护保养

1. **电极清洁**：使用后清水擦拭
2. **导线检查**：定期更换老化导线
3. **设备校准**：每半年校准一次
4. **存放环境**：干燥、避光
