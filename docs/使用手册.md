## 四、操作步骤

### 4.1 连接设备

```
1. 打开设备电源
2. 打开手机蓝牙
3. 打开APP
4. 搜索并连接设备
5. 等待连接成功提示
```

### 4.2 放置电极

**根据治疗模式选择位置：**

| 模式 | 位置 | 说明 |
|------|------|------|
| 运动改善 | 运动皮层 | 头顶偏后 |
| 睡眠改善 | 前额叶 | 额头两侧 |
| 认知改善 | 顶叶 | 头顶两侧 |

**放置步骤：**
```
1. 清洁皮肤
2. 撕开电极贴片
3. 贴在指定位置
4. 连接电极线
5. 确认连接牢固
```

### 4.3 设置参数

**首次使用建议参数：**

| 参数 | 建议值 |
|------|--------|
| 频率 | 10 Hz |
| 电流 | 0.5 mA |
| 持续时间 | 10 分钟 |
| 波形 | 方波 |

**设置步骤：**
```
1. 选择治疗模式
2. 设置频率
3. 设置电流（从低开始）
4. 设置时间
5. 确认设置
```

### 4.4 开始治疗

```
1. 确认所有设置
2. 点击开始按钮
3. 感受电流刺激（轻微刺痛感）
4. 如不适，立即按急停
5. 治疗结束后，设备自动停止
```

### 4.5 结束治疗

```
1. 等待设备自动停止
2. 断开电极连接
3. 取下电极贴片
4. 清洁皮肤
5. 关闭设备电源
6. 记录使用日志
```

## 五、参数调整

### 5.1 频率选择

| 频率 | 效果 | 适用 |
|------|------|------|
| 1-5 Hz | 放松 | 睡眠 |
| 10-20 Hz | 运动改善 | 震颤 |
| 40-60 Hz | 认知改善 | 记忆力 |
| 100-200 Hz | 镇痛 | 疼痛 |

### 5.2 电流调整

**原则：**
- 从低开始（0.5mA）
- 逐步增加
- 感到明显刺激即可
- 不要超过2mA

### 5.3 时间控制

| 情况 | 时间 |
|------|------|
| 首次使用 | 5-10分钟 |
| 适应后 | 15-20分钟 |
| 最大时间 | 30分钟 |
| 每日次数 | 1-2次 |

## 八、不良反应

### 8.1 常见反应（正常）

| 反应 | 说明 | 处理 |
|------|------|------|
| 轻微刺痛 | 电流刺激 | 正常，可接受 |
| 皮肤发红 | 电流作用 | 通常自行消退 |
| 轻微头晕 | 电流影响 | 降低电流或停止 |

### 8.2 不良反应（需停止）

| 反应 | 处理 |
|------|------|
| 头痛 | 立即停止，休息 |
| 恶心 | 立即停止，就医 |
| 皮肤过敏 | 停止，清洁皮肤 |
| 心悸 | 立即停止，就医 |
| 视力模糊 | 立即停止，就医 |
| 癫痫发作 | 立即停止，紧急就医 |

### 8.3 紧急情况

**立即停止使用并就医：**
- 严重头痛
- 胸闷气短
- 意识模糊
- 持续不适

## 十、故障排除

### 10.1 设备问题

|------|---------|------|
