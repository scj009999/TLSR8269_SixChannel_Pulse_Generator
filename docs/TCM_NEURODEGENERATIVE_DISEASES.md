## 一、总论

### 1.1 中医对脑的认识

《黄帝内经》云：
> **"脑为髓之海"**
> 
> **"头者，精明之府"**

**髓的生成**：
```
肾精 → 骨髓 → 脊髓 → 脑髓
         ↑
    脾胃运化水谷精微
```

**核心观点**：
- 脑髓由肾精所化
- 依赖脾胃运化的水谷精微充养
- 脑主神明，统帅全身

### 1.2 神经退行性疾病的共同病机

## 二、帕金森病（颤证）

### 2.1 病机

**《黄帝内经》**：
> **"诸风掉眩，皆属于肝"**
> 
> **"诸寒收引，皆属于肾"**

**《证治准绳》**：
> **"筋脉约束不住而莫能任持，风之象也"**

**病机层次**：
```
肾精亏虚 → 水不涵木 → 肝阳上亢 → 肝风内动 → 震颤
    ↑                                              ↓
脾胃虚损 → 气血不足 → 筋脉失养 ←──────────────────┘
```

### 2.2 辨证分型

| 证型 | 主症 | 治法 | 代表方 |
|------|------|------|--------|
| **风阳内动** | 震颤剧烈，头晕耳鸣 | 镇肝熄风 | 镇肝熄风汤 |
| **痰热风动** | 震颤伴胸闷痰多 | 清热化痰 | 黄连温胆汤 |
| **气血亏虚** | 震颤无力，面色萎黄 | 大补气血 | 八珍汤 |
| **髓海不足** | 震颤伴健忘痴呆 | 补肾填精 | 地黄饮子 |
| **阳气虚衰** | 震颤伴畏寒肢冷 | 补肾温阳 | 右归丸 |

### 2.3 经颅脉冲刺激方案

| 频率 | 功效 | 穴位 | 对应症状 |
|------|------|------|----------|
| 1-5Hz | 镇静安神 | 百会、神庭 | 焦虑失眠 |
| 10-20Hz | 平肝熄风 | 太阳、率谷 | 震颤 |
| 40-50Hz | 活血通络 | 风池、风府 | 僵直 |

## 六、气功导引法

### 6.1 通用功法

#### 6.1.1 八段锦

**推荐动作**：

| 动作 | 功效 | 适用病症 |
|------|------|----------|
| **两手托天理三焦** | 调理气机 | 所有脑病 |
| **左右开弓似射雕** | 舒展筋脉 | 帕金森、渐冻人 |
| **调理脾胃须单举** | 健脾益气 | 重症肌无力 |
| **五劳七伤往后瞧** | 舒缓颈肩 | 老年痴呆 |
| **摇头摆尾去心火** | 平肝熄风 | 帕金森 |
| **两手攀足固肾腰** | 补肾填精 | 所有脑病 |
| **攒拳怒目增气力** | 养肝明目 | 重症肌无力 |
| **背后七颠百病消** | 醒脑开窍 | 老年痴呆 |

#### 6.1.2 六字诀

**发音与脏腑对应**：

| 发音 | 脏腑 | 功效 | 适用病症 |
|------|------|------|----------|
| **嘘** | 肝 | 平肝熄风 | 帕金森 |
| **呵** | 心 | 清心安神 | 老年痴呆 |
| **呼** | 脾 | 健脾益气 | 重症肌无力 |
| **呬** | 肺 | 补肺益气 | 渐冻人（呼吸肌） |
| **吹** | 肾 | 补肾填精 | 所有脑病 |
| **嘻** | 三焦 | 疏通气机 | 所有脑病 |

#### 6.1.3 太极拳

**功效**：
- 缓慢柔和，适合运动障碍患者
- 意念引导，调神醒脑
- 整体运动，疏通经络
- 呼吸配合，调理气机

### 6.2 专用功法

#### 6.2.1 帕金森病导引法

**步骤**：
1. **站桩**：双脚与肩同宽，膝盖微屈，意守丹田（5分钟）
2. **震颤放松**：自然站立，全身放松，让震颤自然发生（3分钟）
3. **缓慢运动**：缓慢抬手、抬腿，配合呼吸（10分钟）
4. **收功**：双手叠放于丹田，静养（2分钟）

**要点**：
- 动作越慢越好
- 意念跟随动作
- 呼吸自然深长

#### 6.2.2 老年痴呆健脑法

**步骤**：
1. **梳头**：十指梳头，从前额到后脑，36次
2. **鸣天鼓**：双手掩耳，食指弹击后脑，36次
3. **搓耳**：搓揉双耳，从上到下，36次
4. **叩齿**：上下牙齿轻叩，36次
5. **吞津**：舌抵上颚，待唾液满口后吞下，9次

**功效**：
- 醒脑开窍
- 补肾填精
- 延缓痴呆

#### 6.2.3 重症肌无力补气法

**步骤**：
1. **仰卧**：平躺，全身放松
2. **腹式呼吸**：吸气腹部隆起，呼气腹部凹陷（10分钟）
3. **意念引导**：吸气时意想清气入脾，呼气时意想浊气排出
4. **收功**：双手叠放于肚脐，静养（5分钟）

**功效**：
- 健脾益气
- 补益中气
- 增强肌力

#### 6.2.4 渐冻人症养护法

**步骤**：
1. **被动运动**：家属帮助活动四肢关节（10分钟）
2. **按摩**：按揉足三里、阳陵泉、合谷等穴位（10分钟）
3. **呼吸训练**：腹式呼吸，延长呼气时间（10分钟）
4. **心理调适**：静坐冥想，保持心态平和（10分钟）

**功效**：
- 延缓肌肉萎缩
- 改善呼吸功能
- 调节心理状态

| 频率 | 中医功效 | 现代机制 | 适用病症 |

### 7.4 治疗方案

#### 帕金森病方案

```
刺激部位：头顶（百会、四神聪）+ 颞部（太阳、率谷）
频率：20Hz（平肝熄风）
时长：20分钟/次
疗程：每日1-2次，4周为一疗程
配合：针刺太冲、合谷 + 中药镇肝熄风汤
```

#### 老年痴呆方案

```
刺激部位：头顶（百会、四神聪）+ 额部（印堂、神庭）
频率：40Hz（活血通络）
时长：30分钟/次
疗程：每日1次，8周为一疗程
配合：针刺足三里、三阴交 + 中药七福饮
```

#### 重症肌无力方案

```
刺激部位：头部（百会）+ 四肢（足三里、阳陵泉）
频率：10Hz（健脾益气）
时长：20分钟/次
疗程：每日1次，12周为一疗程
配合：艾灸足三里 + 中药补中益气汤
```

#### 渐冻人症方案

```
刺激部位：头部（百会、风池）+ 四肢（合谷、曲池）
频率：10Hz（健脾益气）+ 40Hz（活血通络）交替
时长：30分钟/次
疗程：每日1次，长期治疗
配合：按摩 + 被动运动 + 中药还少丹
```
