## 一、固本培元总则

### 1.1 慢性病特点

慢性病患者长期身体消耗，常见：
- **气血亏虚**：面色萎黄，神疲乏力
- **阴阳失调**：畏寒肢冷或五心烦热
- **脏腑虚弱**：脾肾亏虚，精血不足
- **痰瘀互结**：久病入络，瘀血阻络

### 1.2 治疗原则

> **"急则治其标，缓则治其本"**
> 
> **"久病必虚，虚则补之"**

**固本培元四步法**：
```
第一步：补气养血 → 恢复元气
    ↓
第二步：健脾益肾 → 培补后天
    ↓
第三步：温阳散寒 → 祛除阴邪
    ↓
第四步：活血通络 → 防止瘀滞
```

### 1.3 首选方剂

**八珍汤**为固本培元首选：
- 气血双补，平和无偏
- 脾胃虚弱者亦可服用
- 加减灵活，适应面广

## 五、食疗与养生

### 5.1 八珍汤食疗方

#### 八珍炖鸡

**材料**：
- 老母鸡1只（约1000g）
- 人参6g（或党参15g）
- 白术9g
- 茯苓9g
- 当归9g
- 川芎6g
- 白芍9g
- 熟地12g
- 甘草3g
- 生姜3片
- 大枣5枚
- 料酒适量
- 盐适量

**做法**：
1. 老母鸡宰杀，去毛内脏，洗净
2. 药材洗净，装入纱布袋
3. 将鸡、药袋、生姜、大枣放入炖盅
4. 加清水适量，隔水炖3小时
5. 加盐调味即可

**功效**：益气养血，补虚强身

**适用**：气血两虚，久病体虚。

**注意**：感冒发热者暂停。

**材料**：
- 人参3g（或党参10g）
- 白术6g
- 茯苓6g
- 当归6g
- 川芎3g
- 白芍6g

## 六、外治法

### 6.1 艾灸法

#### 常用穴位

| 穴位 | 定位 | 功效 | 适用病症 |
|------|------|------|----------|
| 百会 | 头顶正中 | 醒脑开窍 | 所有脑病 |
| 足三里 | 膝下3寸 | 健脾益气 | 重症肌无力 |
| 关元 | 脐下3寸 | 补肾固本 | 渐冻人症 |
| 气海 | 脐下1.5寸 | 益气培元 | 所有虚证 |
| 肾俞 | 第2腰椎棘突下 | 补肾壮阳 | 所有脑病 |
| 脾俞 | 第11胸椎棘突下 | 健脾益气 | 脾胃虚弱 |
| 肝俞 | 第9胸椎棘突下 | 疏肝理气 | 肝郁气滞 |

#### 操作方法

1. **温和灸**：点燃艾条，对准穴位，距离皮肤2-3cm，熏烤10-15分钟
2. **雀啄灸**：艾条上下移动，如鸟啄食，每穴5-10分钟
3. **回旋灸**：艾条左右回旋，扩大受热面积，每穴10-15分钟

**注意**：
- 防止烫伤
- 阴虚火旺者慎用
- 孕妇禁用腰腹部穴位

### 6.2 足浴法

#### 温肾壮阳方

**材料**：
- 艾叶30g
- 红花15g
- 生姜30g
- 花椒10g
- 附子10g（先煎）
- 桂枝15g

**做法**：
1. 将药物加水煮沸30分钟
2. 倒入足浴盆，加温水调至40-45℃
3. 浸泡双足20-30分钟
4. 每日1次

**功效**：温肾壮阳，活血通络

**适用**：阳虚畏寒，四肢不温。

**注意**：
- 水温不宜过高
- 时间不宜过长
- 糖尿病足患者慎用

### 6.3 按摩法

#### 头部按摩

**方法**：
1. **开天门**：两拇指从眉心交替推至发际，36次
2. **推坎宫**：两拇指从眉心分推至太阳穴，36次
3. **揉太阳**：按揉太阳穴，顺时针、逆时针各36次
4. **梳头**：十指从前额梳至后脑，36次

**功效**：醒脑开窍，安神定志

---

#### 腹部按摩

**方法**：
1. **摩腹**：手掌顺时针摩腹，36次
2. **揉中脘**：按揉中脘穴，顺时针、逆时针各36次
3. **揉神阙**：按揉肚脐，顺时针、逆时针各36次
4. **揉关元**：按揉关元穴，顺时针、逆时针各36次

**功效**：健脾益气，补肾固本

## 七、重要提示

### 7.1 用药原则

1. **辨证施治**：根据证型选择方剂
2. **个体化**：根据体质调整剂量
3. **循序渐进**：从小剂量开始，逐步调整
4. **长期坚持**：慢性病需长期治疗
5. **定期复查**：监测肝肾功能

### 7.2 禁忌事项

| 情况 | 注意 |
|------|------|
| 感冒发热 | 暂停补益药 |
| 腹泻 | 慎用滋腻药 |
| 失眠 | 晚上少服兴奋药 |
| 高血压 | 慎用升阳药 |
| 糖尿病 | 去冰糖、蜂蜜 |
| 阴虚火旺 | 慎用温阳药 |
| 痰湿内盛 | 慎用滋腻药 |

### 7.3 就医建议

**出现以下情况，请立即就医**：
- 症状加重或出现新症状
- 服药后出现不适
- 出现过敏反应
- 病情急剧变化
