## 一、帕金森病（颤证）

### 1.1 镇肝熄风汤

**来源**：张锡纯《医学衷中参西录》

**组成**：
| 药物 | 剂量 | 功效 |
|------|------|------|
| 怀牛膝 | 30g | 引血下行 |
| 生赭石 | 30g（先煎） | 镇肝降逆 |
| 生龙骨 | 15g（先煎） | 平肝潜阳 |
| 生牡蛎 | 15g（先煎） | 软坚散结 |
| 生龟板 | 15g（先煎） | 滋阴潜阳 |
| 生杭芍 | 15g | 养血柔肝 |
| 玄参 | 15g | 滋阴清热 |
| 天冬 | 15g | 养阴润燥 |
| 川楝子 | 6g | 疏肝理气 |
| 生麦芽 | 6g | 疏肝和胃 |
| 茵陈 | 6g | 清利湿热 |
| 甘草 | 4.5g | 调和诸药 |

**功效**：镇肝熄风，滋阴潜阳

**主治**：肝阳上亢，肝风内动。症见头晕目眩，耳鸣耳聋，肢体震颤，或半身不遂。

**用法**：水煎服，每日1剂，分2次温服。

**注意**：脾胃虚寒者慎用。

**用法**：水煎服，每日1剂，分2次温服。

**注意**：阴虚火旺者慎用。

## 七、外治法

### 7.1 艾灸法

#### 常用穴位

| 穴位 | 定位 | 功效 | 适用病症 |
|------|------|------|----------|
| 百会 | 头顶正中 | 醒脑开窍 | 所有脑病 |
| 足三里 | 膝下3寸 | 健脾益气 | 重症肌无力 |
| 关元 | 脐下3寸 | 补肾固本 | 渐冻人症 |
| 气海 | 脐下1.5寸 | 益气培元 | 所有虚证 |
| 肾俞 | 第2腰椎棘突下 | 补肾壮阳 | 所有脑病 |

#### 操作方法

1. **温和灸**：点燃艾条，对准穴位，距离皮肤2-3cm，熏烤10-15分钟
2. **雀啄灸**：艾条上下移动，如鸟啄食，每穴5-10分钟
3. **回旋灸**：艾条左右回旋，扩大受热面积，每穴10-15分钟

**注意**：
- 防止烫伤
- 阴虚火旺者慎用
- 孕妇禁用腰腹部穴位

---

### 7.2 按摩法

#### 头部按摩

**方法**：
1. **开天门**：两拇指从眉心交替推至发际，36次
2. **推坎宫**：两拇指从眉心分推至太阳穴，36次
3. **揉太阳**：按揉太阳穴，顺时针、逆时针各36次
4. **梳头**：十指从前额梳至后脑，36次

**功效**：醒脑开窍，安神定志

---

#### 四肢按摩

**方法**：
1. **按揉足三里**：拇指按揉，顺时针、逆时针各36次
2. **按揉合谷**：拇指按揉，酸胀为度，2-3分钟
3. **按揉太冲**：拇指按揉，酸胀为度，2-3分钟
4. **拍打胆经**：沿大腿外侧拍打，从上到下，36次

**功效**：疏通经络，调和气血

---

### 7.3 足浴法

#### 温肾壮阳方

**材料**：
- 艾叶30g
- 红花15g
- 生姜30g
- 花椒10g

**做法**：
1. 将药物加水煮沸30分钟
2. 倒入足浴盆，加温水调至40-45℃
3. 浸泡双足20-30分钟
4. 每日1次

**功效**：温肾壮阳，活血通络

**注意**：
- 水温不宜过高
- 时间不宜过长
- 糖尿病足患者慎用

## 八、重要提示

### 8.1 用药原则

1. **辨证施治**：根据证型选择方剂
2. **个体化**：根据体质调整剂量
3. **循序渐进**：从小剂量开始，逐步调整
4. **长期坚持**：慢性病需长期治疗
5. **定期复查**：监测肝肾功能

### 8.2 禁忌事项

| 情况 | 注意 |
|------|------|
| 感冒发热 | 暂停补益药 |
| 腹泻 | 慎用滋腻药 |
| 失眠 | 晚上少服兴奋药 |
| 高血压 | 慎用升阳药 |
| 糖尿病 | 去冰糖、蜂蜜 |

### 8.3 就医建议

**出现以下情况，请立即就医**：
- 症状加重或出现新症状
- 服药后出现不适
- 出现过敏反应
- 病情急剧变化
