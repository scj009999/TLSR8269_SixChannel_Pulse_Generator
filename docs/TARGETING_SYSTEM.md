# 经颅脉冲刺激靶点定位系统

## 一、定位原理

### 1.1 10-20 EEG电极定位系统（简化版）

```
                    鼻根 (Nasion)
                      │
         ┌────────────┼────────────┐
         │            │            │
    ┌────┤    FP1    │    FP2    ├────┐

    │    │     ┌──────┴──────┐     │    │
    │    │     │      Fz     │     │    │
    │    │     │    (额中)    │     │    │
    │    │     └──────┬──────┘     │    │
    │    │            │            │    │
    │    │    C3      │      C4    │    │

测量方法:
1. 测量鼻根到枕骨隆突的距离（头前后径）
2. 测量左右耳前点距离（头左右径）
3. 按10-20比例确定各点位置
```

### 1.2 帕金森治疗靶点

基于刘河生教授研究，主要刺激靶点：

| 靶点 | 位置 | 功能 | 备注 |
|------|------|------|------|
| **M1** | 初级运动皮层 | 运动控制 | 主要靶点 |
| **SMA** | 辅助运动区 | 运动计划 | 辅助靶点 |
| **DLPFC** | 背外侧前额叶 | 认知功能 | 情绪调节 |
| **FP1/FP2** | 前额叶 | 综合功能 | 易定位 |

### 1.3 六通道靶点分配方案

```
方案A：双靶点双侧（推荐）
═══════════════════════════════════════

通道0 (CH0) → 左M1  (C3位置偏前2cm)
通道1 (CH1) → 右M1  (C4位置偏前2cm)
通道2 (CH2) → 左SMA (Cz位置偏左2cm)
通道3 (CH3) → 右SMA (Cz位置偏右2cm)
通道4 (CH4) → 左DLPFC (F3位置)
通道5 (CH5) → 右DLPFC (F4位置)


方案B：单靶点多参数（强化刺激）
═══════════════════════════════════════

通道0-1 → M1 双侧 (40Hz, 相位差0°)
通道2-3 → M1 双侧 (40Hz, 相位差180°) - 深度刺激
通道4-5 → 备用/辅助


方案C：多靶点轮换
═══════════════════════════════════════

时段1 (0-10min): CH0-CH1 → M1
时段2 (10-20min): CH2-CH3 → SMA
时段3 (20-30min): CH4-CH5 → DLPFC
```

### 2.3 阻抗检测定位验证

```
通过测量电极-皮肤阻抗判断接触质量：

阻抗值范围：
┌─────────────────────────────────────┐
│  < 5kΩ    │ 优秀接触，可开始治疗      │
│  5-10kΩ   │ 良好接触，建议添加凝胶    │
│  10-20kΩ  │ 一般接触，必须添加凝胶    │
│  > 20kΩ   │ 接触不良，重新放置电极    │
│  > 100kΩ  │ 电极脱落，无法治疗        │
└─────────────────────────────────────┘

自动检测流程：
1. 放置电极
2. 设备自动测量各通道阻抗
3. OLED显示各通道阻抗值
4. 阻抗过高时发出警告
5. 所有通道<10kΩ时才允许启动
```

### 3.2 靶点选择菜单

```cpp
// 治疗靶点选择
enum BrainTarget {
    TARGET_M1,          // 初级运动皮层
    TARGET_SMA,         // 辅助运动区
    TARGET_DLPFC,       // 背外侧前额叶
    TARGET_FP,          // 前额叶（简易）
    TARGET_CUSTOM       // 自定义
};

void selectTarget(BrainTarget target) {
    switch(target) {
        case TARGET_M1:
            // M1双侧刺激
            Pulse.configureChannel(0, 40, 5000, 0);  // 左M1
            Pulse.configureChannel(1, 40, 5000, 0);  // 右M1
            Pulse.configureChannel(2, 0, 0, 0);       // 关闭
            Pulse.configureChannel(3, 0, 0, 0);
            break;
            
        case TARGET_SMA:
            // SMA双侧刺激
            Pulse.configureChannel(0, 0, 0, 0);
            Pulse.configureChannel(1, 0, 0, 0);
            Pulse.configureChannel(2, 40, 5000, 0);  // 左SMA
            Pulse.configureChannel(3, 40, 5000, 0);  // 右SMA
            break;
            
        case TARGET_DLPFC:
            // DLPFC双侧刺激
            Pulse.configureChannel(4, 40, 5000, 0);  // 左DLPFC
            Pulse.configureChannel(5, 40, 5000, 0);  // 右DLPFC
            break;
            
        case TARGET_FP:
            // 简易前额刺激（适合家庭使用）
            Pulse.configureChannel(0, 40, 5000, 0);  // FP1
            Pulse.configureChannel(1, 40, 5000, 0);  // FP2
            break;
    }
}
```

## 四、定位精度验证

### 4.1 功能性验证

```
M1区验证方法（运动诱发电位）：

1. 刺激M1区
2. 观察对侧手指是否轻微抽动
3. 如有抽动，说明定位准确
4. 如无抽动，微调电极位置

注意：
- 电流<2mA时可能无明显抽动
- 以患者主观感觉为准（轻微刺痛感）
- 首次使用建议在医生指导下进行
```

### 4.2 影像辅助（可选）

```
如有条件，可使用以下方法辅助定位：

1. 红外脑成像 (fNIRS)
   - 检测刺激区域血氧变化
   - 验证靶点激活

2. 经颅磁刺激 (TMS) 定位
   - 先用TMS确定热点
   - 再用TES（经颅电刺激）治疗

3. MRI导航（专业级）
   - 个体化头颅MRI
   - 精确靶点定位
```

## 六、注意事项

### 6.1 定位准确性

- **不要求绝对精确**：经颅电刺激作用范围较广（约2-3cm直径）
- **相对位置更重要**：左右对称、前后比例正确即可
- **个体化调整**：根据患者反应微调

### 6.2 安全边界

```
禁止刺激区域：
┌─────────────────────────────────────┐
│  ✗ 眼眶周围（眼睛上方2cm内）         │
│  ✗ 太阳穴（颞动脉区域）              │
│  ✗ 后脑勺（小脑区域，除非专业指导）   │
│  ✗ 颈部（颈动脉窦）                  │
│  ✗ 皮肤破损处                        │
└─────────────────────────────────────┘

安全区域：
┌─────────────────────────────────────┐
│  ✓ 前额（FP1/FP2）                  │
│  ✓ 头顶运动区（C3/C4）              │
│  ✓ 头顶中央（Cz附近）               │
│  ✓ 前额侧面（F3/F4）                │
└─────────────────────────────────────┘
```

### 6.3 常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 阻抗过高 | 皮肤干燥/电极老化 | 清洁皮肤/更换电极/添加凝胶 |
| 左右不对称 | 头带偏移 | 重新调整位置 |
| 刺激感过强 | 电流过大 | 降低强度 |
| 无刺激感 | 接触不良 | 检查连接 |

---

*靶点定位是治疗有效性的关键，但不必过度追求精确。经颅电刺激的作用范围较广，合理的近似定位即可产生治疗效果。*
