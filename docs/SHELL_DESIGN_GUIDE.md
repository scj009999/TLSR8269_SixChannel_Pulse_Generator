# 3D外壳设计指南

> **说明**：收到PCB样品后，测量实际尺寸，设计医疗设备外壳。

---

## 一、外壳设计要求

### 1.1 医疗标准

| 标准 | 要求 | 说明 |
|------|------|------|
| **GB 9706.1-2020** | 安全防护 | 电气安全 |
| **YY 0505-2012** | 电磁兼容 | EMI屏蔽 |
| **生物相容性** | ISO 10993 | 皮肤接触材料 |

### 1.2 设计原则

1. **安全第一**：绝缘、隔离、防护
2. **人体工学**：手持舒适，操作方便
3. **可靠性**：结构稳固，耐用
4. **可维护**：便于拆卸维修
5. **美观**：医疗风格，简洁专业

## 四、材料选择

### 4.1 推荐材料

| 材料 | 特性 | 适用 | 成本 |
|------|------|------|------|
| **ABS** | 易加工，强度高 | 外壳主体 | 低 |
| **PC** | 透明，耐冲击 | 窗口/面板 | 中 |
| **TPU** | 柔软，防滑 | 握把/垫脚 | 中 |
| **硅胶** | 亲肤，绝缘 | 电极接触面 | 高 |

### 4.2 医疗级要求

- **生物相容性**：ISO 10993认证
- **阻燃性**：UL94 V-0级
- **绝缘性**：体积电阻率>10^15Ω·cm

## 五、3D建模步骤

### 5.1 使用Fusion 360（推荐）

#### 步骤1：创建新项目
1. 打开Fusion 360
2. 新建设计
3. 保存为"PulseTherapy_Shell"

#### 步骤2：绘制PCB轮廓
1. 创建草图
2. 绘制60×40mm矩形（PCB尺寸）
3. 偏移2.5mm（壁厚+间隙）
4. 拉伸20mm（高度）

#### 步骤3：设计外壳主体
```
1. 创建外壳基体（70×50×25mm）
2. 挖空内腔（65×45×20mm）
3. 添加圆角（R3mm）
4. 添加拔模斜度（1°）
```

#### 步骤4：添加接口开孔
```
1. 前面板：LED窗口（3×Φ3mm）
2. 前面板：电源键（12×8mm）
3. 后面板：6路电极接口（6×Φ4mm）
4. 后面板：USB-C（9×3mm）
5. 后面板：急停按钮（Φ16mm）
```

#### 步骤5：添加固定结构
```
1. PCB固定柱（4×Φ3mm，高8mm）
2. 螺丝孔（4×M2.5）
3. 卡扣结构（上下盖连接）
4. 定位销（防止错位）
```

#### 步骤6：设计上下盖
```
1. 分割外壳为上下两部分
2. 上盖：按钮、LED窗口
3. 下盖：电极接口、USB、急停
4. 添加密封圈槽（可选）
```

### 5.2 导出STL

1. 选择要打印的零件
2. 右键 → "另存为STL"
3. 选择精度（高）
4. 保存

## 七、装配验证

### 7.1 收到外壳后检查

- [ ] 尺寸是否匹配PCB
- [ ] 接口位置是否对齐
- [ ] 按钮是否灵活
- [ ] LED窗口是否透光
- [ ] 螺丝孔是否对齐

### 7.2 装配测试

1. 将PCB放入下盖
2. 对准固定柱
3. 安装上盖
4. 拧紧螺丝
5. 测试所有功能

### 7.3 问题修正

| 问题 | 解决 |
|------|------|
| 尺寸偏小 | 加大内腔尺寸 |
| 接口错位 | 调整开孔位置 |
| 按钮卡滞 | 加大按钮间隙 |
| 强度不足 | 增加壁厚或加强筋 |

## 八、开模准备（批量生产）

### 8.1 确认设计

验证3D打印样品后，确认：
- [ ] 结构设计合理
- [ ] 装配工艺可行
- [ ] 外观符合要求
- [ ] 成本可接受

### 8.2 开模流程

1. **设计模具**
   - 拔模斜度≥1°
   - 壁厚均匀
   - 避免倒扣

2. **选择厂家**
   - 华秋合作模具厂
   - 或自行联系

3. **模具费用**
   - 简易模具：¥5000-10000
   - 精密模具：¥15000-30000

4. **注塑成本**
   - ABS原料：¥15-25/kg
   - 加工费：¥0.5-1/件
