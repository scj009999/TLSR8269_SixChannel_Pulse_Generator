# 证据收集：经颅脉冲刺激治疗帕金森病

## 一、核心证据 - 刘河生教授研究

### 1.1 研究概况
- **研究者**：昌平实验室 刘河生教授团队
- **发表时间**：2026年2月5日
- **发表期刊**：《自然》(Nature) - 全球顶级科学期刊
- **研究性质**：世界首次发现帕金森病底层功能网络机制

### 1.2 核心发现
- **发现内容**：帕金森病核心病变环路——"躯体认知环路"
- **治疗靶点**：针对这一网络进行直接干预
- **临床效果**：治疗2周后，躯体认知靶点组有效率达55.5%
- **对比数据**：传统大脑运动区刺激有效率仅22.2%

### 1.3 产业化进展
- **设备名称**：精准脑环路刺激系统
- **研发公司**：北京银河脑科学公司

- **临床应用**：全国60余家医院，累计治疗超3000例
- **整体有效率**：突破70%

## 二、安全性证据 - tACS/tDCS临床研究

### 2.1 经颅交流电刺激(tACS)安全性
- **研究来源**：福建医科大学 Cell子刊论文
- **研究对象**：脊髓小脑性共济失调3型(SCA3)患者
- **安全性结论**：安全可行，未发现任何治疗相关不良事件
- **效果**：通过调节大脑功能连接，改善共济失调严重程度

### 2.2 经颅直流电刺激(tDCS)安全性
- **研究来源**：Nature Medicine 二期随机对照试验
- **研究对象**：174名中重度抑郁障碍(MDD)患者
- **刺激参数**：0.5-2mA微弱直流电
- **安全性结论**：安全性、耐受性良好
- **效果**：10周治疗，应答率、缓解率是假刺激组的2-3倍

### 2.3 深部脑刺激(DBS)安全性参考
- **手术性质**：微创手术，并发症控制在1%以下
- **最严重并发症**：脑内出血，发生率不到1%
- **安全性评价**：在外科手术里属于相对安全的手术
