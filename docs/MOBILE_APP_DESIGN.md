# 手机APP设计方案 - 医患交互系统

## 一、项目概述

### 1.1 目标
开发一款手机APP，连接开源经颅脉冲治疗仪，实现：
- 患者远程调整治疗参数
- 医生远程监控和指导
- 治疗数据记录和分析
- 患者社区互助

### 1.2 核心价值
| 功能 | 价值 |
|------|------|
| 远程调参 | 患者无需频繁去医院 |
| 医生监控 | 医生可实时了解治疗效果 |
| 数据记录 | 长期追踪治疗进展 |
| 社区互助 | 患者间经验分享 |

## 四、技术实现

### 4.1 技术栈

| 层级 | 技术 | 说明 |
|------|------|------|
| 前端 | Flutter | 跨平台(iOS/Android) |
| 后端 | Node.js + Express | RESTful API |
| 数据库 | PostgreSQL + Redis | 主库 + 缓存 |
| 消息队列 | RabbitMQ | 异步处理 |
| 蓝牙 | flutter_blue | BLE通信 |
| 推送 | Firebase FCM | 消息推送 |
| 图表 | fl_chart | 数据可视化 |

### 4.2 蓝牙通信协议

```
服务UUID: 0x180A (Device Information)
特征UUID: 0x2A50 (设备状态)
          0x2A51 (治疗控制)
          0x2A52 (参数配置)
          0x2A53 (实时数据)

数据格式 (JSON):
{
  "cmd": "start",
  "params": {
    "mode": "parkinson_std",
    "duration": 20,
    "channels": [
      {"ch": 0, "freq": 40, "duty": 50},
      {"ch": 1, "freq": 40, "duty": 50}
    ]
  }
}

响应格式:
{
  "status": "ok",
  "data": {
    "elapsed": 120,
    "remaining": 1080,
    "current": 1800,
    "impedance": 5200
  }
}
```

### 4.3 API设计

```
POST   /api/v1/auth/login          # 登录
POST   /api/v1/auth/register       # 注册
GET    /api/v1/patients            # 获取患者列表
GET    /api/v1/patients/:id        # 获取患者详情
POST   /api/v1/treatments          # 创建治疗记录
GET    /api/v1/treatments/:id      # 获取治疗记录
POST   /api/v1/parameters/request  # 申请参数调整
POST   /api/v1/parameters/approve  # 审批参数调整
GET    /api/v1/analytics/symptoms  # 症状分析
GET    /api/v1/analytics/treatment # 治疗分析
```

## 五、安全设计

### 5.1 数据安全
- 端到端加密（TLS 1.3）
- 敏感数据AES-256加密存储
- 数据库访问权限控制
- 定期安全审计

### 5.2 通信安全
- 蓝牙配对加密
- 设备认证（防止未授权连接）
- 指令签名验证
- 防重放攻击

### 5.3 医疗安全
- 参数修改需医生确认
- 敏感操作二次确认
- 异常自动报警
- 紧急停止优先

### 5.4 隐私保护
- 符合《个人信息保护法》
- 数据最小化原则
- 患者授权机制
- 数据删除权

## 九、总结

手机APP是连接患者和医生的桥梁，让远程医疗成为可能。通过：
- **实时连接**：患者随时治疗，医生随时监控
- **数据驱动**：基于数据分析优化治疗方案
- **社区互助**：患者间分享经验，共同对抗疾病
