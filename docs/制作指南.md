## 四、焊接步骤

### 4.1 焊接顺序

```
1. 电源部分
2. 主控芯片
3. 晶振和复位电路
4. 光耦和输出电路
5. 蓝牙天线
6. 按键和LED
7. 电极接口
```

### 4.2 关键步骤

**步骤1：焊接主控芯片**

```
注意：
- 对齐引脚
- 先焊对角固定
- 逐个引脚焊接
- 检查短路
```

**步骤2：焊接光耦**

```
注意：
- 注意方向（有标记）
- 确保隔离距离
- 检查导通
```

**步骤3：焊接限流电阻**

```
注意：
- 阻值100Ω
- 功率0.25W以上
- 确保可靠连接
```

### 4.3 检查要点

| 检查项 | 方法 | 标准 |
|--------|------|------|
| 短路 | 万用表蜂鸣档 | 无短路 |
| 开路 | 万用表电阻档 | 连接正常 |
| 极性 | 目视检查 | 方向正确 |
| 焊点 | 放大镜 | 饱满光亮 |

## 八、常见问题

### 8.1 焊接问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 虚焊 | 温度不够 | 提高温度，加助焊剂 |
| 短路 | 焊锡过多 | 吸锡带清理 |
| 芯片损坏 | 静电/过热 | 防静电，控制温度 |

### 8.2 烧录问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 无法连接 | 接线错误 | 检查SWD接口 |
| 烧录失败 | 芯片锁定 | 解锁后重试 |
| 程序不跑 | 晶振问题 | 检查晶振焊接 |

### 8.3 功能问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 无输出 | 限流电阻开路 | 检查电阻 |
| 电流不准 | ADC校准问题 | 重新校准 |
| 蓝牙断开 | 天线问题 | 检查天线焊接 |
