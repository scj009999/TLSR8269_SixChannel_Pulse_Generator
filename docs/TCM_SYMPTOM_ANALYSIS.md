### 1.3 治疗原则

> **"治痿者，独取阳明"**
> 
> **"肾主骨，生髓，通于脑"**

**治疗三步法**：
```
第一步：固本培元 → 八珍汤为主
    ├─ 补气养血，恢复元气
    └─ 健脾益肾，培补后天

第二步：温煦阳气 → 加附子、炮姜、桂枝
    ├─ 附子：回阳救逆，温补脾肾
    ├─ 炮姜：温中散寒，温煦中焦
    └─ 桂枝：温阳通脉，通达四肢

第三步：养血安神 → 加龙眼肉、益智仁
    ├─ 龙眼肉：养血补气，安神定志
    └─ 益智仁：温肾固精，防止病情进展
```

#### 方剂原理深度解析

**1. 八珍汤固本培元**

```
四君子汤（补气） + 四物汤（补血） = 八珍汤（气血双补）

功效：
├─ 补气：人参、白术、茯苓、甘草
├─ 补血：当归、川芎、白芍、熟地
└─ 气血双补：气能生血，血能载气

原理：
├─ 气为血之帅：气能生血、行血、摄血
├─ 血为气之母：血能载气、养气
└─ 气血互生：补气以生血，养血以益气
```

**2. 附子温煦阳气**

```
附子：回阳救逆，温补脾肾

功效：
├─ 回阳救逆：挽救衰微之阳气
├─ 温补脾肾：温煦脾肾之阳
├─ 散寒止痛：祛除阴寒之邪
└─ 温通经脉：温通四肢经脉

原理：
├─ 附子大辛大热，为回阳救逆第一品
├─ 温补脾肾之阳，使阳气生发
├─ 阳气生长，则寒气消退
└─ 先煎30-60分钟，降低毒性
```

**3. 炮姜温中散寒**

```
炮姜：温中散寒，温经止血

功效：
├─ 温中散寒：温煦中焦，散寒止痛
├─ 温经止血：温经止血，防止出血
└─ 温脾止泻：温脾止泻，防止泄泻

原理：
├─ 炮姜为干姜炮制品，性味辛热
├─ 温中焦脾胃之阳
├─ 与附子配伍，增强温阳之力
└─ 温而不燥，守而不走
```

**4. 桂枝通达阳气**

```
桂枝：发汗解肌，温通经脉，助阳化气

功效：
├─ 温阳通脉：温通经脉，通达四肢
├─ 助阳化气：助阳气化气行水
├─ 平冲降逆：平冲降逆，防止气逆
└─ 通利九窍：通达九窍，开窍醒神

原理：
├─ 桂枝辛甘温，入心、肺、膀胱经
├─ 温通经脉，使阳气通达四肢九窍
├─ 与附子配伍，增强温阳通脉之力
└─ 通达四肢，改善肢体冰冷
```

**5. 龙眼肉养血安神**

```
龙眼肉：补益心脾，养血安神

功效：
├─ 补益心脾：大补心脾之气血
├─ 养血安神：养血安神，改善睡眠
├─ 益智健脑：益智健脑，改善记忆
└─ 补气养血：补气养血，增强体质

原理：
├─ 龙眼肉甘温，入心、脾经
├─ 大补心血，安神定志
├─ 用量宜大，15-30g
├─ 与八珍汤配伍，增强养血之力
└─ 改善失眠、健忘、心悸
```

**6. 益智仁防止病情进展**

```
益智仁：温肾固精，缩尿止遗，温脾止泻

功效：
├─ 温肾固精：温肾固精，防止精气外泄
├─ 缩尿止遗：缩尿止遗，防止尿频
├─ 温脾止泻：温脾止泻，防止泄泻
└─ 防止病情进展：温肾固精，防止病情恶化

原理：
├─ 益智仁辛温，入脾、肾经
├─ 温肾固精，防止精气外泄
├─ 起到"刹车"效果，防止病情进展
├─ 与附子配伍，增强温肾之力
└─ 温脾止泻，防止脾胃虚寒
```

### 渐冻人症的治疗原理

```
八珍汤（固本培元）
    ├─ 气血双补，恢复元气
    └─ 健脾益肾，培补后天

+ 附子、炮姜、桂枝（温煦阳气）
    ├─ 附子：回阳救逆，温补脾肾
    ├─ 炮姜：温中散寒，温煦中焦
    └─ 桂枝：温阳通脉，通达四肢

+ 龙眼肉、益智仁（养血安神）
    ├─ 龙眼肉：养血补气，安神定志
    └─ 益智仁：温肾固精，防止病情进展

= 温补气血，益肾填精，通络起痿，防止病情进展
```

- **阳气生长，则寒气消退**
- **桂枝通达阳气，使阳气通达四肢九窍**
