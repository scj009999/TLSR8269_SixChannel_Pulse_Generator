# 功率调节方案对比与推荐

> **问题**：脉冲输出功率和强度调节，是用软件实现还是外接电位器？

---

## 一、方案对比

### 方案一：纯软件调节（PWM数字控制）

| 项目 | 说明 |
|------|------|
| **实现方式** | TLSR8269 PWM输出 → 恒流源 → 电极 |
| **调节精度** | 0.1%（10位PWM） |
| **调节范围** | 0-100% |
| **成本** | 低（无需额外元件） |
| **复杂度** | 中（需要编程） |

**优点**：
- ✅ 精确控制，数字调节
- ✅ 可编程，多种刺激模式
- ✅ 软件限流，安全保护
- ✅ 手机APP远程控制
- ✅ 数据记录，治疗追踪
- ✅ 自动校准，一致性高

**缺点**：
- ❌ 需要调试软件
- ❌ 依赖稳定电源
- ❌ 老人可能不习惯

**适用场景**：
- 科技接受度高的用户
- 需要精确治疗的场景
- 数据记录需求

---

### 方案二：纯硬件调节（电位器模拟控制）

| 项目 | 说明 |
|------|------|
| **实现方式** | 电位器分压 → 运放 → 恒流源 → 电极 |
| **调节精度** | 约5%（受电位器质量影响） |
| **调节范围** | 0-100% |
| **成本** | 极低（仅电位器） |
| **复杂度** | 低（纯硬件） |

**优点**：
- ✅ 简单直观，旋钮操作
- ✅ 成本低，无需编程
- ✅ 可靠性高，无软件bug
- ✅ 老人易用
- ✅ 不依赖电池（如果用电位器直接控制）

**缺点**：
- ❌ 精度低，调节粗糙
- ❌ 不可编程，模式单一
- ❌ 无数据记录
- ❌ 易误触改变设置
- ❌ 无远程控制

**适用场景**：
- 老年用户
- 简单应用场景
- 成本敏感

## 三、推荐方案：混合调节

### 3.1 为什么推荐混合方案？

1. **安全性**：软件限流保护 + 硬件急停
2. **易用性**：电位器直观 + 显示清晰
3. **精确性**：软件微调达到医疗级精度
4. **灵活性**：可升级软件增加功能

### 3.2 实现方案

#### 硬件部分

```
┌─────────────────────────────────────┐
│         前面板布局                   │
│                                     │
│  ┌─────────┐  ┌─────────┐          │

│  │   🔴    │  │   🟥    │          │
│  └─────────┘  └─────────┘          │
│                                     │
│  ┌─────────────────────────┐       │
│  │    总强度调节旋钮        │       │
│  │      ┌───────┐          │       │
│  │      │  0-100 │          │       │
│  │      └───────┘          │       │
│  └─────────────────────────┘       │
│                                     │
│  ┌─────────────────────────┐       │
│  │      OLED显示屏          │       │
│  │  CH1: 45% ████████░░   │       │
│  │  CH2: 30% █████░░░░░   │       │
│  │  ...                   │       │

│                                     │
│  [模式] [开始] [停止] [设置]        │
└─────────────────────────────────────┘
```

#### 电路设计

```
电位器（10kΩ）──→ ADC（PA2）──→ 软件读取
                          ↓
                    ┌─────────┐
                    │  计算   │
                    │ 总强度  │
                    └────┬────┘
                         ↓
手机APP/BLE ──→ 软件细调 ──→ 最终强度
                         ↓
                    ┌─────────┐
                    │  PWM输出 │
                    │ 0-100%  │
                    └────┬────┘
                         ↓
                    ┌─────────┐
                    │ 恒流源  │
                    │ 驱动    │
                    └────┬────┘
                         ↓
                    电极输出
```

#### 软件逻辑

```c
// 读取电位器（粗调）
uint16_t adc_value = adc_read(PA2);
uint8_t coarse = (adc_value * 100) / 4095;  // 0-100%

// 手机APP细调（-10% ~ +10%）
int8_t fine = ble_get_fine_adjust();  // -10 ~ +10

// 计算最终强度
int16_t final = coarse + fine;
if (final > 100) final = 100;
if (final < 0) final = 0;

// 设置PWM
set_intensity(ch, (uint8_t)final);

// 显示更新
oled_display("CH1: %d%%", final);
```

### 3.3 使用流程

#### 首次使用

```
1. 戴上头带，贴好电极
2. 打开电源开关
3. 旋转电位器到最低（0%）
4. 手机APP连接蓝牙
5. APP上选择"初次使用模式"
6. 缓慢旋转电位器增加强度
7. 感到轻微刺痛即停止
8. APP记录最佳强度
```

#### 日常使用

```
1. 戴上头带
2. 打开电源
3. 旋转电位器到上次记录位置
4. 按"开始"按钮
5. 如需微调，用手机APP
6. 治疗结束自动停止
```

#### 紧急情况

```
1. 按红色急停按钮 → 立即切断所有输出
2. 或旋转电位器到0%
3. 或手机APP点击"急停"
4. 三种方式均可紧急停止
```

## 七、最终推荐

### 强烈推荐：混合调节方案

**理由**：
1. **安全性最高**：多重保护
2. **易用性最好**：老少皆宜
3. **功能最全**：软件可升级
4. **成本合理**：仅增加¥12

**实施建议**：
1. **必须实现**：
   - 1个总强度电位器
   - 1个急停按钮
   - OLED显示
   - 软件限流保护

2. **建议实现**：
   - 手机APP控制
   - 数据记录
   - 多种刺激模式
   - 定时功能

3. **可选实现**：
   - 6路独立电位器（成本高）
   - 语音控制
   - 云端数据同步
