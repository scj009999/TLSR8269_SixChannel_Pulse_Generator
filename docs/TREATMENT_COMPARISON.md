## 一、背景说明

帕金森病是一种常见的神经退行性疾病，全球患者超过1000万。随着病情进展，患者会出现震颤、僵直、运动迟缓等症状，严重影响生活质量。

目前主流治疗方案各有特点，患者和家属需要充分了解各种方案的利弊，做出知情选择。

## 二、治疗方案对比

### 2.1 对比总览

| 对比维度 | 药物治疗 | 脑深部电刺激(DBS) | 经颅电刺激(tDCS/tACS) | 中医综合调理 |
|----------|----------|-------------------|----------------------|-------------|
| **治疗原理** | 补充多巴胺 | 植入电极刺激脑核团 | 头皮电极微弱电流 | 整体调理，标本兼治 |
| **侵入性** | 无 | 有（开颅手术） | 无 | 无 |
| **费用** | 中等 | 20-40万元 | 数千-数万元 | 较低 |
| **可逆性** | 可逆 | 部分可逆 | 完全可逆 | 可逆 |
| **副作用** | 运动并发症等 | 感染、出血、硬件故障 | 轻微皮肤刺激 | 较少 |
| **适用阶段** | 全阶段 | 中晚期 | 全阶段 | 全阶段 |
| **居家使用** | 是 | 需专业调试 | 是 | 是 |
| **个性化** | 有限 | 有限 | 较高 | 高 |

### 2.2 详细对比

#### （1）药物治疗

**优势**：
- 历史悠久，方案成熟
- 起效较快
- 便于调整剂量

**局限**：
- 长期使用可能出现运动并发症
- 不能阻止病情进展
- 部分患者效果逐渐减退

**适用人群**：早期患者、手术禁忌者

---

#### （2）脑深部电刺激（DBS）

**优势**：
- 对部分患者效果显著
- 可减少药物剂量
- 技术不断进步

**需要考虑的因素**：
- 需要开颅手术植入硬件
- 存在手术风险（感染、出血等）
- 硬件可能故障，需更换
- 费用较高
- 术后需专业团队长期随访调试
- 并非所有患者都适合

**适用人群**：药物效果减退、出现严重运动并发症的中晚期患者

**重要提示**：手术决策需充分评估，选择有经验的医疗团队。

---

#### （3）经颅电刺激（tDCS/tACS）

**优势**：
- 非侵入性，安全性高
- 可居家使用
- 费用相对较低
- 可与其他治疗联合
- 完全可逆

**局限**：
- 效果个体差异大
- 需长期坚持
- 最佳参数仍在研究中

**适用人群**：各阶段患者，尤其适合早期干预和辅助治疗

**研究进展**：
- 多项研究显示对运动症状有改善
- 安全性良好，副作用轻微
- 居家使用方案逐渐成熟

---

#### （4）中医综合调理

**优势**：
- 整体观念，辨证论治
- 副作用较少
- 可改善整体状态
- 可与其他治疗联合

**方法**：
- 中药调理
- 针灸
- 推拿
- 气功导引
- 情志调摄

**适用人群**：各阶段患者，尤其适合体质调理

## 三、开源经颅脉冲治疗仪特点

### 3.1 设计目标

本项目旨在开发一种**低成本、非侵入性、可居家使用**的神经调控设备，为帕金森病患者提供更多选择。

### 3.2 核心特点

| 特点 | 说明 |
|------|------|
| **非侵入性** | 头皮表面刺激，无需手术 |
| **低成本** | 物料成本<200元 |
| **开源** | 硬件设计、软件代码完全开放 |
| **可定制** | 频率、强度、时间可调 |
| **多通道** | 6路独立输出 |
| **安全保护** | 多重电流限制、阻抗检测 |

### 3.3 技术参数

| 参数 | 规格 |
|------|------|
| 输出通道 | 6路 |
| 频率范围 | 1Hz - 8MHz |
| 占空比精度 | 0.01% |
| 电流限制 | ≤2mA |
| 电压限制 | ≤24V |
| 通信接口 | UART/I2C |
| 供电 | 3.3V |

### 3.4 安全设计

| 保护机制 | 说明 |
|----------|------|
| 电流限制 | 硬件+软件双重限制 |
| 阻抗检测 | 自动检测接触阻抗 |
| 急停按钮 | 一键切断输出 |
| 超时保护 | 自动关闭 |
| 隔离设计 | 医疗级光耦隔离 |

## 四、患者选择建议

### 4.1 选择原则

1. **知情同意**：充分了解各种方案的利弊
2. **个体化**：根据病情、年龄、经济状况选择
3. **阶梯治疗**：从低风险方案开始
4. **联合应用**：多种方法结合可能效果更好
5. **专业指导**：任何治疗都应在医生指导下进行

### 4.2 不同阶段的考虑

| 病程阶段 | 建议 |
|----------|------|
| **早期** | 药物+生活方式调整+非侵入性刺激 |
| **中期** | 优化药物+非侵入性刺激+中医调理 |
| **晚期** | 综合评估，考虑侵入性治疗 |

## 五、重要提醒

### 5.1 关于治疗期望

- 目前没有治愈帕金森病的方法
- 各种治疗的目标是改善症状、提高生活质量
- 效果因人而异，需耐心尝试

### 5.2 关于新兴疗法

- 经颅电刺激仍在研究中
- 最佳参数方案尚未统一
- 建议在专业指导下使用

### 5.3 关于开源设备

- 本项目为开源研究项目
- 使用需自行承担风险
- 建议与医生讨论后使用
- 不替代正规医疗
