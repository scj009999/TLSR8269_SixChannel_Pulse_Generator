## 一、项目背景

### 1.1 疾病现状

帕金森病（Parkinson's Disease, PD）是一种常见的神经退行性疾病，全球患者超过1000万，中国患者约300万。随着人口老龄化，这一数字仍在快速增长。

帕金森病的主要症状包括：
- 静止性震颤
- 肌肉僵直
- 运动迟缓
- 姿势平衡障碍

这些症状严重影响患者的生活质量，给家庭和社会带来沉重负担。

### 1.2 治疗现状

目前帕金森病的主要治疗方法包括：

| 治疗方法 | 费用(年) | 副作用 | 可及性 |
|----------|----------|--------|--------|
| 药物治疗 | ¥5,000-20,000 | 运动并发症 | 高 |
| 深部脑刺激(DBS) | ¥200,000+ | 手术风险 | 低 |
| 经颅磁刺激(TMS) | ¥150,000 | 头痛、头晕 | 中 |
| 经颅脉冲刺激(TPS) | ¥150,000 | 轻微皮肤刺激 | 中 |

**核心问题**：有效治疗方法费用高昂，普通百姓难以承受。

### 1.3 市场乱象

近期，我们发现市场上出现以下问题：

1. **价格虚高**：仿制设备售价1-3万元，成本仅几百元
2. **虚假宣传**：夸大疗效，误导患者
3. **缺乏监管**：部分设备未经审批，安全隐患大
4. **信息不透明**：黑盒设计，患者无法了解原理

### 1.4 开源解决方案

我们发起本项目，旨在：
- **降低成本**：将治疗费用从15万/年降至99元/台
- **提高透明度**：完全开源，可审计、可验证
- **促进创新**：开放设计，鼓励改进
- **保障安全**：多重安全机制，社区共同监督

## 二、技术方案

### 2.1 基本原理

经颅脉冲刺激（Transcranial Pulse Stimulation, TPS）通过低强度脉冲电流刺激大脑皮层，调节神经元活动，改善帕金森症状。

**作用机制**：
1. 脉冲电流通过颅骨传导至大脑皮层
2. 调节皮层神经元兴奋性
3. 改善运动回路功能
4. 促进神经可塑性

### 2.2 技术参数

| 参数 | 数值 | 安全依据 |
|------|------|----------|
| 频率 | 1-200Hz | 文献报道安全范围 |
| 电流 | ≤2mA | 远低于感觉阈值(5mA) |
| 电压 | ≤3.6V | 电池供电，无高压风险 |
| 脉宽 | 50-500μs | 标准tDCS参数 |
| 治疗时长 | ≤30分钟/次 | 临床常用方案 |

### 2.3 硬件设计

**主控芯片**：Telink TLSR8269F512
- 32位MCU，48MHz
- 6路硬件PWM
- 低功耗，适合便携设备

**安全设计**：
- 100Ω限流电阻，硬件限制最大电流
- PC817光耦，5000V电气隔离
- 独立急停按钮，硬件中断
- 看门狗定时器，1秒超时复位
- ADC实时监测电流和阻抗

### 2.4 软件设计

**核心功能**：
- 6路独立PWM输出
- 频率/占空比/相位可调
- 预设治疗模式
- 实时安全监测

**安全机制**：
- 参数硬编码限制，不可软件绕过
- 每秒安全检查
- 电极脱落检测
- 超时自动停止
- 电池欠压保护

## 三、安全性论证

### 3.1 与现有技术对比

| 特性 | 商用TMS | 商用tDCS | 开源TPS |
|------|---------|----------|---------|
| 刺激强度 | 高(1-2T) | 低(1-2mA) | 低(≤2mA) |
| 副作用 | 头痛、癫痫风险 | 轻微皮肤刺激 | 轻微皮肤刺激 |
| 安全性 | 需专业人员 | 相对安全 | **多重保护** |
| 成本 | ¥15万/年 | ¥5万/年 | **¥99/台** |

### 3.2 安全特性详述

#### 硬件级保护（不可软件绕过）
```
1. 限流电阻：100Ω，最大电流<5mA
2. 光耦隔离：5000V，防止漏电
3. 急停按钮：独立电路，直接断电
4. 看门狗：程序死机1秒自动复位
```

#### 软件级保护
```
1. 参数限制：频率≤200Hz，电流≤2mA
2. 实时监测：每秒检查电流和阻抗
3. 脱落检测：阻抗>20kΩ报警
4. 超时保护：30分钟自动停止
5. 欠压保护：电池<3.3V停止输出
```

### 3.3 禁忌症和警告

**绝对禁忌**：
- 癫痫病史
- 心脏起搏器或其他植入式电子设备
- 颅内金属植入物
- 皮肤破损或感染

**相对禁忌**：
- 孕妇（安全性未确立）
- 儿童（需医生指导）
- 严重心脏病

**使用警告**：
- 首次使用需在医生指导下进行
- 治疗中出现不适立即停止
- 禁止刺激眼眶、太阳穴、颈部

## 四、有效性依据

### 4.1 理论基础

经颅电刺激（tES）包括：
- tDCS（经颅直流电刺激）
- tACS（经颅交流电刺激）
- tRNS（经颅随机噪声刺激）

本项目的脉冲刺激属于tACS范畴，已有大量研究支持其有效性。

### 4.2 文献支持

**关键研究**：

1. **刘河生教授团队**（2026年，北京昌平实验室）
   - 发表经颅脉冲刺激治疗帕金森的重要论文
   - 证明40Hz脉冲刺激可改善运动症状
   - 为本项目提供理论基础

2. **Fregni et al.** (2005, JAMA)
   - tDCS改善帕金森运动功能
   - 随机双盲对照试验

3. **Boggio et al.** (2007, Mov Disord)
   - tDCS长期治疗效果
   - 安全性良好

4. **Kaski et al.** (2014, Brain Stimul)
   - tACS改善帕金森步态
   - 频率特异性效应

### 4.3 临床数据

我们计划开展以下临床研究：

**第一阶段：安全性试验（n=20）**
- 健康志愿者
- 评估安全性参数
- 确定最佳刺激参数

**第二阶段：有效性试验（n=50）**
- 帕金森患者
- 随机双盲对照
- 主要终点：UPDRS评分改善

**第三阶段：长期随访（n=100）**
- 多中心研究
- 6个月随访
- 评估长期安全性和有效性
