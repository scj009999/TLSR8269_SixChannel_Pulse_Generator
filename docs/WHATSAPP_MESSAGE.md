【帕金森病治疗的真相】

没有"最好"的方案，只有"最适合"的方案。

目前主要选择：

1️⃣ 药物治疗
- 历史悠久，方案成熟
- 但长期使用可能出现运动并发症

2️⃣ DBS手术
- 对部分患者效果显著
- 但需要开颅，有风险
- 费用高

3️⃣ 经颅电刺激（tDCS/tACS）
- 非侵入性，安全
- 可居家使用
- 费用较低
- 效果因人而异

4️⃣ 中医调理
- 整体调理
- 副作用少
- 效果较慢
