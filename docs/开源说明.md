## 二、技术背景

本项目基于以下研究成果：

### 2.1 核心论文

**刘河生教授团队研究成果**  
发表于《自然》(Nature)，2026年2月5日

**主要发现：**
- 揭示帕金森病"躯体认知环路"机制
- 针对该网络进行干预，有效率55.5%
- 已获批3项国家医疗器械注册证
- 在全国60余家医院应用

### 2.2 技术原理

**经颅脉冲刺激 (TPS)：**
- 通过头皮电极施加微弱电流
- 调节大脑神经元活动
- 改善帕金森症状

**刺激参数：**
- 频率：1-200 Hz
- 电流：≤ 2 mA
- 波形：方波/正弦波
- 持续时间：1-30 分钟

## 三、硬件设计

### 3.1 主控芯片

**Telink TLSR8269F512**
- 32位RISC-V内核
- 512KB Flash
- 48KB SRAM
- 6路PWM输出
- BLE 4.2

### 3.2 电源设计

**输入：** USB 5V 或 锂电池 3.7V  
**输出：** 6路独立刺激通道

### 3.3 安全保护

| 保护措施 | 说明 | 参数 |
|---------|------|------|
| 硬件限流 | 100Ω电阻 | 最大输出 < 5mA |
| 光耦隔离 | PC817 | 5000V隔离 |
| 急停按钮 | 硬件中断 | 立即切断输出 |
| 看门狗 | 定时器 | 1秒超时复位 |
| ADC监测 | 实时检测 | 每秒安全检查 |
