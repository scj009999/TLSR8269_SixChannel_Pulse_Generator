# 经颅脉冲治疗仪 - 医疗安全设计规范

## 项目使命

为帕金森叠加综合症患者提供**可负担的开源治疗设备**。

- **目标成本**: < 200元人民币（物料成本）
- **开源协议**: GPL v3 + CERN OHL v2（硬件）
- **监管路径**: 向国家药监局提交创新医疗器械特别审批

---

## 一、电气安全设计

### 1.1 输出隔离设计

```
┌─────────────────────────────────────────────────────────┐
│                    安全隔离架构                           │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  ┌──────────────┐      ┌──────────────┐                │
│  │   控制部分    │      │   输出部分    │                │
│  │  (低压安全区) │      │  (患者连接区)  │                │
│  │              │      │              │                │
│  │  TLSR8269    │      │  光耦隔离     │───► 电极输出    │
│  │  3.3V MCU    │─────►│  + 限流电路   │    (安全电压)   │
│  │              │      │              │                │
│  │  电池供电     │      │  独立电源     │                │
│  │  4.2V锂电池   │      │  (隔离DC-DC)  │                │
│  └──────────────┘      └──────────────┘                │
│                                                         │
│  隔离要求:                                               │
│  - 患者电路与地隔离 ≥ 1500V AC                          │
│  - 漏电流 < 10µA                                       │
│  - 输出电压限制 < 36V DC (安全特低电压)                  │
└─────────────────────────────────────────────────────────┘
```

### 1.2 输出限流保护

```
脉冲输出通道 (每路):

TLSR8269 PWM ──► [100Ω限流电阻] ──► [光耦隔离] ──► [输出缓冲] ──► 电极
                                        │
                                        ▼
                                  [稳压二极管]
                                  (钳位保护)

参数:
- 限流电阻: 100Ω (限制最大电流 33mA @ 3.3V)
- 光耦: PC817 或类似 (隔离电压 5000V)
- 输出钳位: 15V稳压管 (防止过压)
- 实际输出到皮肤: < 5mA (安全电流)
```

### 1.3 紧急停止电路

```
硬件急停 (独立电路，不依赖软件):

        VCC
         │
    ┌────┴────┐
    │  按键    │  [急停按钮 - 常闭]
    │  STOP   │
    └────┬────┘
         │
    ┌────┴────┐
    │  光耦    │───► 切断所有输出电源
    │         │
    └────┬────┘
         │
        GND

软件急停:
- 看门狗定时器 (1秒内必须喂狗)
- 输出超时保护 (单次治疗最大30分钟)
- 异常检测自动断电
```

## 三、治疗参数规范

### 3.1 安全参数范围

基于刘河生教授论文的公开参数（假设为40Hz脉冲）:

| 参数 | 最小值 | 默认值 | 最大值 | 安全限制 |
|------|--------|--------|--------|----------|
| 频率 | 1Hz | 40Hz | 200Hz | 硬限制 |
| 脉冲宽度 | 50µs | 200µs | 1000µs | 软限制 |
| 输出电流 | 0.1mA | 2mA | 5mA | **硬限制** |
| 治疗时间 | 1min | 20min | 30min | 超时保护 |
| 占空比 | 10% | 50% | 80% | - |

### 3.2 参数锁定机制

```c
// 安全参数检查 (硬件层)
#define SAFE_FREQ_MIN       1
#define SAFE_FREQ_MAX       200
#define SAFE_CURRENT_MAX    5       // 5mA 绝对上限
#define SAFE_PULSE_WIDTH_MAX 1000   // 1ms
#define SAFE_TREATMENT_MAX  30      // 30分钟

// 超出安全范围自动截断
if (target_current > SAFE_CURRENT_MAX) {
    target_current = SAFE_CURRENT_MAX;
    alarm_set(ALARM_OVER_CURRENT);
}
```

## 四、可靠性设计

### 4.1 硬件看门狗

```
外部看门狗芯片 (如 MAX6814):

TLSR8269 ──► [GPIO喂狗] ──► WDI (看门狗输入)
                                │
                                ▼
                           [1秒超时]
                                │
                                ▼
                           RESET ──► 强制复位MCU

如果程序死机，1秒内自动复位
```

### 4.2 输出监控

```
每路输出实时监测:

PWM输出 ──► [电流采样电阻] ──► [ADC检测] ──► MCU
                │
                ▼
           实际输出电流
           
如果检测到:
- 开路 (无电流) → 报警
- 短路 (过流) → 立即切断 + 报警
- 异常波形 → 报警
```

### 4.3 自检程序

```c
// 开机自检
void power_on_self_test(void) {
    // 1. 检查所有输出是否开路
    // 2. 检查急停按钮状态
    // 3. 检查电池电压
    // 4. 检查温度传感器
    // 5. 输出测试脉冲（不连接患者时）
    
    if (all_tests_passed) {
        led_status_green();
        enable_output();
    } else {
        led_status_red();
        disable_output_permanently();
        show_error_code();
    }
}
```
