## 二、内容规范

### 2.1 必须包含的内容

**每个视频必须：**

1. **口播免责声明**
   ```
   "本项目仅供技术交流，不构成医疗建议。
   请在专业医生指导下进行任何治疗。"
   ```

2. **字幕免责声明**
   ```
   画面底部固定显示：
   "技术分享 | 非医疗建议 | 请咨询医生"
   ```

3. **结尾信息**
   ```
   - 项目主页：GitHub链接
   - 许可证：GPL-3.0
   - 声明：使用风险自负
   ```

### 2.2 禁止内容

| 类型 | 示例 | 后果 |
|------|------|------|
| 疗效承诺 | "治愈帕金森" | 违规，可能封号 |
| 医疗建议 | "你应该这样做" | 非法行医嫌疑 |
| 商业推广 | "购买我的设备" | 违规，封号 |
| 攻击他人 | "医院都是骗人的" | 违规，封号 |
| 暴露隐私 | 展示患者面部 | 侵犯隐私 |
| 诱导捐赠 | "请捐款支持" | 违规 |

### 2.3 敏感词规避

**避免使用：**
- ❌ "治愈"
- ❌ "根治"
- ❌ "特效"
- ❌ "神医"
- ❌ "秘方"
- ❌ "包治"
- ❌ "100%有效"

**建议使用：**
- ✅ "辅助改善"
- ✅ "缓解症状"
- ✅ "技术分享"
- ✅ "个人经验"
- ✅ "仅供参考"
- ✅ "因人而异"

## 五、评论管理

```
问：这个芯片哪里买？
答：可以在Telink官网或淘宝购买，
    注意选择正品。详细清单在项目主页。
```

**使用问题：**
```
问：电流设置多少合适？
答：建议从0.5mA开始，逐步增加。
    但请务必在医生指导下调整参数。

```

回复：谢谢！希望技术能帮助更多人。
    但请记住，医生才是治疗的主体。

### 5.2 谨慎回复

**疗效询问：**
```
问：用了有效果吗？
答：个体差异很大，效果因人而异。
    本项目仅分享技术，不承诺疗效。
    请咨询您的医生。
```

**购买询问：**
```
问：哪里可以买到？
答：本项目不销售设备，只分享技术资料。
    您可以自行制作，但需具备电子制作能力。
    制作和使用风险自负。
```

**医疗建议：**
```
问：我应该怎么治疗？
答：抱歉，我们无法提供医疗建议。
    请咨询您的主治医生，
    或前往正规医院就诊。
```

### 5.3 删除评论

**以下评论应删除：**
- 广告推销
- 医疗骗局
- 人身攻击
- 泄露隐私
- 违法信息

## 六、风险应对

### 6.1 被质疑时的应对

**质疑1："你这是非法行医！"**

应对：
```
我们明确声明：
1. 本项目不是医疗服务
2. 不提供医疗建议
3. 不销售医疗设备
4. 仅分享技术资料

所有内容都包含免责声明，
强调必须在医生指导下使用。
```

**质疑2："你这是在骗钱！"**

应对：
```
本项目：
- 完全免费开源
- 不收取任何费用
- 不销售任何产品
- 不接受任何捐赠

所有资料在GitHub免费下载，
遵循GPL-3.0开源许可证。
```

**质疑3："出事了谁负责？"**

应对：
```
我们明确声明：
1. 使用风险自负
2. 必须在医生指导下使用
3. 项目不承担任何责任
4. 所有资料包含完整免责声明

请仔细阅读免责声明后再决定是否使用。
```

### 6.2 被举报时的应对

**步骤1：自查**
- 检查视频内容是否违规
- 检查是否包含疗效承诺
- 检查是否包含医疗建议

**步骤2：申诉**
- 如果内容合规，提交申诉
- 说明项目性质（技术分享）
- 提供免责声明证据

**步骤3：调整**
- 如果确实违规，立即删除
- 调整内容后重新发布
- 加强免责声明

## 九、紧急情况处理

### 9.1 账号被封

**立即行动：**
1. 检查违规原因
2. 提交申诉
3. 准备备用账号
4. 通知社区

### 9.2 负面舆情

**应对步骤：**
1. 评估影响范围
2. 准备回应声明
3. 联系平台处理
4. 必要时暂停发布

### 9.3 法律风险

**应对措施：**
1. 立即停止相关活动
2. 咨询法律专业人士
3. 保留所有证据
4. 配合调查
