## 一、安全架构总览

```
┌─────────────────────────────────────────────────────────────┐
│                    安全保护层级                              │
├─────────────────────────────────────────────────────────────┤
│  Layer 1: 硬件级保护（独立运行，不依赖软件）                  │
│    ├── 急停按钮（常闭，硬件切断）                            │
│    ├── 电流保险丝（2mA硬件限制）                             │
│    ├── 电压钳位（24V TVS二极管）                             │
│    └── 光耦隔离（PC817×6，医疗级隔离）                       │
├─────────────────────────────────────────────────────────────┤
│  Layer 2: 软件级保护（从机独立运行）                         │
│    ├── 参数二次校验（和主设备阈值对齐）                      │
│    ├── 实时电流检测（INA219，50ms周期）                      │
│    ├── 实时阻抗检测（100ms周期）                             │
│    ├── 通信超时保护（30秒无命令停机）                        │
│    └── 治疗时长限制（最大30分钟）                            │
├─────────────────────────────────────────────────────────────┤
│  Layer 3: 通信级保护（主从协同）                             │
│    ├── CRC16校验（防止数据错乱）                             │
│    ├── 应答+重传机制（3次重试）                              │
│    ├── 心跳检测（10秒间隔，30秒超时）                        │
│    └── 参数二次强校验（主设备先拦截）                        │
├─────────────────────────────────────────────────────────────┤
│  Layer 4: 系统级保护（开机自检）                             │
│    ├── 时钟检测（32M + 32K）                                 │
│    ├── Flash/RAM检测                                         │
│    ├── 电源检测                                              │
│    ├── ADC/PWM检测                                           │
│    └── 急停/BLE检测                                          │
└─────────────────────────────────────────────────────────────┘
```

## 二、硬件级保护（Layer 1）

### 2.1 急停按钮

| 属性 | 说明 |
|------|------|
| 连接位置 | PC2 (GPIO 18) |
| 类型 | 常闭 (NC) |
| 响应时间 | < 10ms |
| 优先级 | 最高（独立于软件） |
| 动作 | 立即切断所有PWM输出 |

**电路设计**：
```
VCC ──[10k上拉]──┬── PC2 (输入)
                 │
                [急停按钮 NC]
                 │
                GND
```

### 2.2 电流限制

| 属性 | 说明 |
|------|------|
| 软件限制 | 2mA |
| 硬件保险丝 | 2.5mA 快熔 |
| 检测方式 | INA219 (I2C) |
| 检测周期 | 50ms |
| 响应时间 | < 100ms |

### 2.3 电压限制

| 属性 | 说明 |
|------|------|
| 工作电压 | 3.3V |
| 最大输出 | 24V (通过升压) |
| 保护器件 | TVS二极管 |
| 钳位电压 | 27V |

### 2.4 光耦隔离

| 属性 | 说明 |
|------|------|
| 器件 | PC817 × 6 |
| 隔离电压 | 5000Vrms |
| 响应时间 | 4μs |
| 用途 | 每通道独立隔离 |

## 三、软件级保护（Layer 2）

### 3.1 参数安全阈值

| 参数 | 最小值 | 最大值 | 说明 |
|------|--------|--------|------|
| 频率 | 0.1 Hz | 1000 Hz | 超出范围拒绝 |
| 脉宽 | 1 μs | 10000 μs | 超出范围拒绝 |
| 强度 | 0 | 100 | 百分比 |
| 时长 | 1 min | 30 min | 超出范围拒绝 |
| 相位 | 0° | 360° | 超出范围拒绝 |

### 3.2 实时检测周期

| 检测项目 | 周期 | 阈值 | 动作 |
|----------|------|------|------|
| 电流 | 50ms | > 2mA | 立即停机 |
| 阻抗 | 100ms | < 1kΩ 或 > 10kΩ | 立即停机 |
| 电压 | 100ms | > 24V | 立即停机 |
| 温度 | 1000ms | > 60°C | 立即停机 |
| 急停 | 10ms | 按下 | 立即停机 |

### 3.3 通信超时保护

```
主设备 ──心跳──> 从机 (每10秒)
  │
  └── 30秒无心跳 ──> 从机自动停机
```

## 四、通信级保护（Layer 3）

### 4.1 数据帧格式

```
+--------+--------+--------+--------+--------+--------+--------+
|  HEAD  |  CMD   |  LEN   |  DATA  |  CRC16 |  TAIL  |
|  0xAA  |  1B    |  1B    |  0-16B |  2B    |  0x55  |
+--------+--------+--------+--------+--------+--------+
```

### 4.2 通信流程

```
主设备          从机
  │              │
  ├─ CMD ───────>│
  │              │
  │<─ ACK ───────┤ (500ms超时)
  │              │
  ├─ CMD ───────>│ (重试1)
  │              │
  │<─ ACK ───────┤
  │              │
  ├─ CMD ───────>│ (重试2)
  │              │
  │<─ ACK ───────┤
  │              │
  ├─ CMD ───────>│ (重试3)
  │              │
  │  无ACK       │
  │              │
  ▼              ▼
  通信故障        保持当前状态
```

### 4.3 主设备参数校验

```
用户输入
  │
  ▼
主设备UI校验（范围检查）
  │
  ▼
主设备二次强校验（医疗级阈值）
  │
  ▼
发送给从机
  │
  ▼
从机三次校验（最终把关）
  │
  ▼
执行输出
```

## 五、系统级保护（Layer 4）

### 5.1 开机自检项目

| 序号 | 项目 | 通过标准 | 失败动作 |
|------|------|----------|----------|
| 1 | 时钟 | 32M±1M, 32K稳定 | 锁机 |
| 2 | Flash | 读写正常, CRC正确 | 锁机 |
| 3 | RAM | Walking bit通过 | 锁机 |
| 4 | 电源 | 3.3V±0.1V | 锁机 |
| 5 | ADC | 读数合理 | 锁机 |
| 6 | PWM | 输出正常 | 锁机 |
| 7 | 急停 | 未按下 | 锁机 |
| 8 | BLE | 初始化成功 | 锁机 |

### 5.2 故障码定义

| 码值 | 含义 | 处理 |
|------|------|------|
| 0x00 | 正常 | 继续运行 |
| 0x01 | 过流 | 停机，检查电极 |
| 0x02 | 过压 | 停机，检查电源 |
| 0x03 | 阻抗低 | 停机，检查接触 |
| 0x04 | 阻抗高 | 停机，检查接触 |
| 0x05 | 过温 | 停机，冷却后再试 |
| 0x06 | 急停 | 复位急停后重启 |
| 0x07 | 通信超时 | 检查蓝牙连接 |
| 0x08 | 参数非法 | 重新配置 |

## 七、应急处理流程

```
故障发生
  │
  ▼
立即停机（硬件+软件）
  │
  ▼
记录故障码
  │
  ▼
LED闪烁报警
  │
  ▼
UART输出故障信息
  │
  ▼
等待人工干预
  │
  ├── 急停：复位按钮
  ├── 过流：检查电极接触
  ├── 过压：检查电源
  └── 通信：检查蓝牙
```
